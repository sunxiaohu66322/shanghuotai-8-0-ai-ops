## 一、怎么用（两种入口，随便挑一种）

### 入口 1 · 网页（推荐）

1. 双击 `启动选品系统.cmd`（服务起来后会自动开 `http://127.0.0.1:9277/`）
2. 浏览器打开 **http://127.0.0.1:9277/v3**
3. 在 Tabbit 里先把淘宝搜索页开好 → 回页面点 **「采集并初筛」**
4. 页面直接给出：保留 N 条 / 剔除 M 条 / 剔除构成 / 品牌自学习明细 / 两张完整表格

### 入口 2 · 命令行（一条命令，不用开服务）

```
python _v3\一键采集初筛.py                 # 采当前淘宝搜索页并筛
python _v3\一键采集初筛.py --scroll 8       # 先往下滚 8 次，把卡都刷出来
python _v3\一键采集初筛.py --dry-learn      # 只预演品牌词，不写词库
python _v3\一键采集初筛.py --cards 采集结果\商品卡_xxx.csv   # 用已有卡片复跑
```

Python 用 `F:\pyenvs\douyin\Scripts\python.exe`。

## 二、初筛的三件事（你定的）

| # | 规则 | 判据 | 依据 |
|:--|:--|:--|:--|
| ① | **旗舰店 → 必删** | 店铺名含「旗舰 / 旗鑑 / 旗絸 / 旗鉴」 | 「不管叫什么，只要店铺标识是旗舰店就必须 pass 掉」 |
| ② | **品牌词命中 → 必删** | 标题 **或** 店铺名 命中品牌词库 | 「像耐克，他不是耐克专卖店，要是耐克我也不可能卖」 |
| ③ | **广告位 / 无效链接 → 去掉** | 卡片带「广告」标记 / URL 里解析不出商品 ID | 「广告页的去掉，无效链接去掉」 |

**其余一律保留。** 老的 A/B/C 三档仍然算、仍然存在（不破坏界面），
**但导出清单只看这三件事** —— 保留 or 剔除，二值。

### 品牌词库三层，任一命中即删

```
① config/brand_library.json           主人词库 + 自学习（几十条，可手工加）
② config/brand_rules.json             知名品牌表（西昊/飞利浦/小米…）
③ 抖店家居类违禁词_剔除单字版.txt      品牌区 19023 条（桌面那个 txt，运行时读）
```

第 ③ 层带**误杀停用词表**（`config/prescreen_rules.json` → `brand_stop_words`）：
「定制」「通用」「正品」这类中文通用词即使出现在品牌表里也不算品牌。

## 三、品牌自学习（你要的那条）

**遇到「奥迪旗舰店」→ 把「奥迪」写进品牌词库 → 下一件哪怕不是旗舰店、只要标题叫「奥迪」，也一起删。**

实现：`server/brand_learn.py`

```
剥掉店铺类型词（旗舰店/官方旗舰店/专卖店/专营店/官方店/自营/工厂店/个人店…）
剥掉类目通用词（灯具/灯饰/照明/户外/装备/服饰/鞋…）
剥掉店铺自造区分词（潮搭/通勤/锐动/海港/内衣/奥莱…）
  ↓
「南极人潮搭旗舰店」→ 南极人潮搭 → 里面含已知品牌「南极人」→ 收「南极人」
「猫人通勤旗舰店」  → 猫人
「回力锐动专卖店」  → 回力
「亚明灯具旗舰店」  → 亚明
```

### 三道挡板（都是实测踩出来的，别删）

| 挡板 | 挡的是什么 | 实例 |
|:--|:--|:--|
| **地名表** | 收录地名会把整片产地的店杀光 | 「顺德乐从户外家具旗舰店」→ 不收录 |
| **通用词表** | 泛词一收录就是灭顶之灾 | 「国货严选旗舰」→「国货」被拒 |
| **已知品牌截断** | 不收组合词 | 「南极人潮搭」→ 只收「南极人」 |

此外：只从**旗舰/官方/专卖/专营**这四类店名里学。工厂店、个人店、无类型后缀的店
**不抽**（它们卖白牌，店名不是牌子）。

**想撤销学习**：`config/brand_library.json.bak-learn-*` 是每次写入前的自动备份，
拷回去即可。想临时看效果不写：页面上把「学到的新品牌词」选成「只预演，不写」。

## 四、产出在哪

```
taobao-picker\采集结果\
    保留_可上货_<关键词>_<时间>.csv     ← 可以直接喂给下载软件的网址清单
    剔除_原因_<关键词>_<时间>.csv       ← 每条的剔除原因，可复盘
```

## 五、接口（给以后接别的程序用）

| 方法 | 路径 | 干什么 |
|:--|:--|:--|
| GET | `/api/v3/ping` | 活着？三个开关现在什么状态？词库多少条？ |
| POST | `/api/v3/collect` | 只采（不筛） |
| POST | `/api/v3/run` | 采集+初筛+自学习+出两份 CSV（主入口） |
| POST | `/api/v3/brand/learn` | 只学：`{shops:["奥迪旗舰店"], dry_run:false}` |
| GET | `/api/v3/brand/list` | 当前品牌词库 |
| GET | `/api/v3/result/latest` | 最近两份清单的文件路径 |

`/api/v3/run` 参数（都可省）：`cdp=9222 keyword="" scroll=0 pages=1
auto_learn=true dry_learn=false use_ai=false items=[...]`

**`use_ai` 默认 false** —— 三件事全是确定性规则，不需要模型。
开了要按 4 条一批、每批最多 420 秒地等，47 张卡要等好几分钟。

## 六、风控边界（实测，不是承诺）

采集只做两件事：**读当前页面已经渲染好的 DOM**、**改滚动位置**。

- 不发 XHR、不点按钮、不进详情页、不加购
- 不和淘宝服务器做任何数据交换（页面自己的请求除外，那是页面本来就要发的）
- 一次 `Runtime.evaluate` 取回整页卡片，不是逐张点

## 七、改配置（都不用改代码）

| 想改什么 | 改哪 |
|:--|:--|
| 关掉「旗舰店必删」 | `prescreen_rules.json` → `store_gate.flagship_exclude_always = false` |
| 品牌货只标记不删 | `prescreen_rules.json` → `brand_gate.wordlib_brand_exclude = false` |
| 加/减误杀停用词 | `prescreen_rules.json` → `brand_stop_words.words` |
| 手工加品牌词 | `config/brand_library.json` → `brands[]` 里加一条，或调 `/api/v3/brand/learn` |
| 关掉广告过滤 | `prescreen_rules.json` → `ad_filter.enabled = false` |

全部**热读**，改完立刻生效，不用重启。
