> 生成 2026-11-09 16:24:17　|　磁盘实测扫描，非人工转述　|　密钥已打码为 `===REDACTED===`
> 这是**桌面软件**，不是网页套壳，也不是网页打包成 EXE。方向别搞反。

## 一、一句话

一套跑在 Windows 本机的「选品 → 采集 → 精筛 → 检测打码 → 出表上架」流水线。
主体是 **Python 3.13 + PyQt6 原生桌面程序**，另挂一个 **6.0 微店后台网页（Flask）** 和一套 **Web 诊断层**；
全部数据落在一个 SQLite（`v3.db`），业务引擎是 `taobao-picker/server/v3/*`。

## 二、三层真源（对应关系，最重要）

| 层 | 目录 | 形态 | 干什么 |
|:--|:--|:--|:--|
| A 桌面壳 | `上货台/` | PyQt6，`run.pyw` 启动 | 12 个步骤页签，人在这里点按钮 |
| B 后端引擎 | `taobao-picker/` | Python 模块 + v3 引擎 | 采集/CDP/初筛/精筛/AI判定/打码/出表/落库，`v3.db` 在这 |
| C 网页 | `微信小店自建上货台/` | Flask + 原生 JS | 「6.0 微店后台管理」，`app.py` 是 9191 的服务本体 |

**谁调谁**：A 的 `app/ui/*.py`（各 Tab）→ `app/bridge.py`（265KB，桌面↔v3 唯一桥）
→ `taobao-picker/server/v3/*`（flow/criteria/ai_fine/pack/…）→ `v3.db`。
A 里 `app/wxserve.py` 把 C 的 `app.py` **import 进同一进程**托管在 9191。
`web_diag/`（9186）是另起进程的**只读诊断层**，每请求起干净子进程调 `app.bridge`，读最新的磁盘代码。

## 三、桌面 12 个页签（`上货台/app/ui/main_window.py:249` 的 `_pages`）

```
1 · 采集初筛  →  2 · 数据包导入  →  2.5 · 商品库  →  2.5.1 · 下载监控
→ 3 · 商品精筛  →  4 · 检测打码  →  4.1 · 主图人工审核  →  4.9 · 主图 AI 重做
→ 5.0 · 上架  →  5.5 · 出表  →  6.0 · 微店后台（内嵌网页）→ 设置/状态
```
各页签是 `QTabWidget.addTab()` 挂的原生 Qt 控件，**没有对应的网页按钮**。
这是 9186 诊断层「看得到数据、按不了精筛/打码/上架」的根本原因。

## 四、端口（本机实测，均以 127.0.0.1 监听）

| 端口 | 进程 | 是什么 | 能不能看到全部功能 |
|:--|:--|:--|:--|
| **9191** | `run.pyw` 内嵌 | 6.0 微店后台管理网页 | 只有 C 层那半套 |
| **9186** | `web_diag/webapp.py` | 8 页签只读诊断/核验层 | 看真数据，无操作按钮 |
| 9187 | `web_diag/dlrunner.py` | 诊断层的下载执行器 | 内部 |
| 8326 | node | 本机 AI 网关，`/v1/chat/completions` | 精筛 AI 判定走它 |
| 19190 | `http.server` | 旧版静态说明书（信息不全，已弃用） | 否 |

**结论：不存在「一个端口能看到 12 步全功能网页」。** 要理解整套系统，读本包，不要只开端口。

## 五、数据（`v3.db`，schema 300，28 张表）

见 `03_数据库结构.md`。核心表：`v3_product`（商品，带 `status`/`pack_code`）、

## 六、AI 判定链路（3.0 精筛）

`tab_fine.py` → `bridge.v3_fine_screen_pro` → `v3/flow.py:fine_screen()`
→ 本地硬闸（`criteria.gate` / 品牌黑标 / 重复图题）判死的不花 token
→ 剩下的 `v3/ai_fine.py:judge` → `ai_providers.py:chat()` → `POST http://127.0.0.1:8326/v1/chat/completions`
→ 两档 verdict（pass / block）写回 `v3_product.status`。
模型档在 `taobao-picker/config/ai_providers.json`（本包已脱敏），热读 mtime，改完不用重启。
