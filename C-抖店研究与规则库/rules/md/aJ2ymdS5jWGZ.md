# 一、平台导向
商家应当依据法律法规及平台规则的相关规定，遵循公平、合法和诚实信用的原则，设定合法、合理的商品价格，并对商品价格进行规范设置，真实宣传。
# 二、违规定义
指商家发布的商品价格、从事的价格宣传等行为违反法律法规、平台规则，或商家通过价格作弊方式吸引用户点击、下单的行为，如虚构被比较价格/折扣、不实价格承诺、低价SKU引流等。
# 三、违规情形
| 常见违规类型 | 情形说明 |
| --- | --- |
| 价格设定不合理 | 如商品销售价格不在所发布类目的常规价格区间内或设置价格显然异常，或店铺内同商品设置多种不合理差异价格，或同商品下各SKU之间的销售价格价差存在显然不合理性等，或赠品标示价格高于主售卖商品 等 情形 |
| 价格虚假或虚构 | 如商家通过虚构被比较价格、虚构优惠折扣、价格宣传虚假等行为，意图通过混淆价格理解，吸引用户点击、下单的情形 |
| 低价SKU作弊 | 如商家将不同类目、品类、规格的商品设置到一个商品链接中，通过不规范SKU设置，意图通过低价SKU引流或吸引用户点击、下单的情形 |
| 物流信息作弊 | 如商家意图通过物流信息作弊（包括但不限于：设置低价高邮、不合理邮费、不合理限售区域范围等作弊行为），吸引用户点击、下单的情形 |
# 四、违规处理
对于商品违规信息（包括但不限于SKU、主图和标题等），平台有权删除、重置违规信息或下架违规商品，并有权根据违规程度采取以下处置措施：
| 违规程度 | 处置措施 |
| --- | --- |
| 近30日商家同一违规行为重复违规次数≤3 | 商品下架 |
| 近30日商家同一违规行为重复违规次数≤5 | 商品下架、店铺限期屏蔽（1日） |
| 近30日商家同一违规行为重复违规次数>5 | 商品下架、店铺限期屏蔽（3日） |
| 若因商家违规行为造成大量消费者投诉、违规商品销量较大、违规商品数较多等造成较大违规影响，或引发舆情、监管投诉，或可能导致平台承担相关责任的 | 商品封禁、店铺停业/店铺清退 |
若商家违规同时，出现下述任一行为，在违规程度基础上平台将视具体情况做升档处置：
关联主体店铺出现同类价格违规行为；
商家存在主观故意，通过作弊行为（如使用变体字、生僻字、异形字、特殊符号、少数民族语言、外语，或存在遮挡、马赛克等）故意绕开平台审核。
# 五、常见违规类型及整改建议
## 5.1 价格设定不合理
| 违规类型 | 违规示例 | 整改建议 |
| --- | --- | --- |
| 商品销售价格不在所发布类目的常规价格区间内或设置价格显然异常 | 标价99999元起的气垫 | ✅ 商家对价格的设定应当遵循公平、合法和诚实信用的原则，在正常市场价格范围内合理定价 ❌ 不以成交为目的，设置99999等显然超出商品合理价格区间的定价 |
| 赠品标示价值高于主售卖商品 | 商品售价288元，赠品标价1761元 | ✅ 按赠品真实价值进行标示 ❌ 标示赠品价值比商品售价还高，虚假诱导消费者 |
## 5.2 价格虚假或虚构
| 违规类型 | 违规示例 | 整改建议 |
| --- | --- | --- |
| 虚构被比较价格 | 某个水杯商品售价50，商家在商品信息上无依据虚构原价1000 | ✅ 商家应当依据法律法规及平台规则的相关规定开展价格信息宣传，保障价格标示、价格对比、价格促销等信息的合法、真实、准确 ✅商家应当对所销售商品依法明码标价，以一般消费者认知为原则，清晰标示不同商品品名及价格 ✅ 开展附条件的价格促销活动，需要明确限时活动持续时间、标注促销活动相关条件，并且活动结束后，需立即调整对应主图价格展示，避免主图价格与实际售卖价格不一致 ❌ 优惠折扣信息虚假、使人误解，或未显著标明优惠折扣使用的限制条件，包括但不限于：刻意抬高售卖价、设置异常高额优惠券售卖低价商品、虚构限时特惠等 ❌ 商品信息宣传不规范，使用违规的价格营销词 ，诱导消费者点击，包括但不限于：跳楼价、清仓价、亏本价、甩卖价、白菜价、恐怖价、自杀价、倒闭价、破产价、处理价等 ❌ 商品主图/标题/详情页等，宣传未注明活动持续时间的限时优惠（如限时特价、限时秒杀），或未说明前提条件的限制性优惠（如直播券、新人优惠），让消费者对商品价格产生混淆或误导等 ❌禁止在标题中宣传价格 |
| 虚构优惠折扣 | 商品主图标注“限时特价”实际为持续性展示 |  |
| 价格宣传虚假或引人误解 | 主图标题宣传799，实际支付价为899 |  |
## 5.3 价格违规-低价SKU作弊
| 违规类型 | 违规示例 | 整改建议 |
| --- | --- | --- |
| 同商品链接中发布跨品类、不同系列、不同规格的低价SKU |  | ✅ 应当将相同类目、相同商品属性/规格的商品发布在一个商品ID或商品链接中出售 ✅ 商家应确保同一商品ID或者商品链接中价格信息真实、准确、合理，避免不同SKU之间出现异常价格差异 ✅ 应当发布真实有效的商品，避免将无库存的商品、非常规商品信息（无意义）、非正常规格的商品 的 SKU与常规SKU发布在同一个商品ID或商品链接中 ❌ 商家将跨类目、跨系列、不同规格等价格显著差异的商品发布在一个商品ID或商品链接中出售 ❌ 商家将不同材质、款式、功能等不同属性的商品发布在一个商品ID或商品链接中出售 ❌ 商家将整套商品/套装商品和单件商品、配件辅料与主件商品发布在同一个商品ID或商品链接中售卖（套装内单件有单独类目承接，仍与套装混搭销售） ❌ 商家将缺货、联系客服、订金、邮费、赠品、换购、支持定制、注意事项、直播间下单、点关注、亮灯牌等非商品常规信息与常规的商品发布在同一个商品ID或商品链接中售卖 ❌ 商家将商品的正常规格进行拆分后发布，设置异常规格低价SKU，但不符合常规购买单位等，如： 纸巾的正常规格以"包"为单位，但商家拆分后以"张"为单位进行销售 以试吃、试用等名义拆分商品，但实际为不推荐购买或不符合消费者购买常理 |
| 套装单件/主件配件混卖 | 床品四件套商品中，单独设置一个‘枕套’低价SKU，套装和单件商品混卖 |  |
| 发布异常规格的不以交易为目的的低价SKU | 发布“一瓣”规格的多肉，且sku中标注“不推荐” |  |
## 5.4 价格违规-物流信息作弊
| 违规类型 | 违规示例 | 整改建议 |
| --- | --- | --- |
| 低价高邮 | 设置券后1分钱水杯+7.9元运费、0.57元粘钩+25元运费 | ✅ 应当合理设置商品价格及与实际情形相符合的邮费，平台会综合邮费和商品展示价格的倍比等，来判断是否存在低价高邮 ❌ 商家通过优惠券等设置低价商品，同时设置异常高邮费（邮费相较于商品本身到手价较高），拉高消费者实际支付价 |
| 设置不合理邮费/运费 | 169元水壶，设置298元显然异常的运费价格 | ✅ 设置运费价格需符合行业常规标准 ❌ 设置不符合行业标准的高运费，或对虚拟物品设置运费等 |
| 设置不合理区域限售 | 设置1元运动鞋，点击后仅限定小范围可买 | ✅ 合理设置商品价格及可售区域，平台会综合常规商品价格、区域限售范围占比识别不合理情况 ❌ 商家展示价格设置低价，同时设置大范围区域限售，限制消费者实际购买，即设置异常低价+区域限售，意图低价sku引流、非实际售卖低价sku商品等 |
# 六、商家申诉
申诉路径：【抖店后台-店铺-申诉与举报-申诉中心-违规申诉】/【抖店后台-违规管理-违规处置-违规详情-去申诉】。
申诉时效：需要在收到违规通知后7天内发起申诉，平台会在申诉页面展示申诉时间倒计时，超时将无法申诉。提交申诉后，平台将会在1-5个工作日内给出申诉审核结果。
申诉结果查看：选择【申诉成功】和【申诉失败】页面，会展示对应的申诉单，商家可以点击【申诉详情】查看申诉结果及判定原因。
