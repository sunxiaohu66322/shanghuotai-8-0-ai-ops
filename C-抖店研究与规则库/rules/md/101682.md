# 一、概述
## 1.1 目的与依据
为明确抖音电商商品品质抽检涉及的品类范围、检测项目及检测依据，便于商家直观了解相关检测范围与要求，根据国家有关法律法规、强制性标准、推荐性标准、行业标准、团体标准、平台协议及《【抖音电商】商品品质抽检规范》等内容，制定本规则。
## 1.2 适用范围
本规则适用于抖音电商平台内销售的商品，包括但不限于本规则检测依据标准清单列明的服饰、鞋靴、母婴喂养用品、玩具、汽车用品、运动户外、家装建材、厨房电器、贵金属珠宝玉石、厨具及餐（饮）具、纸尿裤、口罩及其他一次性卫生用品、宠物生活用品、床上用品、食品、化妆品及其他日用化学品、箱包、生活电器、3C数码等商品。
对于未列明的商品品类，平台有权结合商品特性、商品明示信息及质量安全风险，按照本规则确定检测项目及检测依据后开展检测。
本规则与《【抖音电商】商品品质抽检规范》共同适用，涉及抽样、检测委托、费用、样品保存、结果通知、申诉及复验等程序事项，适用《【抖音电商】商品品质抽检规范》。本规则与《【抖音电商】商品品质抽检规范》不一致的，以《【抖音电商】商品品质抽检规范》为准。
# 二、检测项目及依据
## 2.1 检测项目
平台根据商品所属品类、商品特性、商品明示信息及质量安全风险，确定一项或多项检测项目。检测项目包括但不限于安全性能、物理及机械性能、电气性能、化学性能、材质及成分、使用性能及功能、规格尺寸、外观工艺，以及商品明示信息、标识标签与说明书核验。标识标签核验仅针对商品明示信息及法定标识要求开展。
## 2.2 检测依据
### 2.2.1 依据范围
平台根据商品实际情况，选择以下一项或多项依据开展检测：
（1）现行有效的法律法规、强制性国家标准及其他强制性要求；
（2）本规则第2.3条列明的产品标准及其规范性附录；
（3）商品明示执行标准，以及商家通过商品标题、详情页、标签、说明书、企业标准、公开声明、质量承诺书等作出的质量承诺；
（4）适用的推荐性国家标准、行业标准、地方标准、团体标准、企业标准等非强制性标准；
（5）前述产品标准引用的检测方法、抽样、术语、限量、标识标签等相关标准。
多项依据同时适用的，优先适用法律法规及强制性标准。非强制性标准根据商品明示执行标准、商家公开声明、平台规则或协议约定、质量承诺等确定其适用性。商家明示的执行标准或质量承诺高于相关标准要求的，以商家的明示承诺为准。
商品无明确适用标准，或者现有标准未覆盖相关检测项目的，可由具备相应资质的第三方检验检测机构采用与商品及检测项目相适应的标准或方法开展检测。
### 2.2.2 引用标准
产品标准引用其他标准时，注明日期的，适用所注明的版本；该版本存在已生效修改单的，修改单一并适用。未注明日期的，适用抽检时现行有效的最新版本及其已生效修改单。
### 2.2.3 修订与替代
本规则列明的标准被修订、替代，或者发生标准号变更、拆分、合并的，适用承接相关技术要求的现行有效标准或相应部分。
### 2.2.4 新旧标准衔接
新版标准尚未实施或新旧版本处于过渡期的，按照标准发布公告规定的实施日期和过渡安排执行。商品生产日期早于新版标准实施日期的，原则上适用生产时有效的标准；法律法规、强制性标准或标准发布公告另有规定的，从其规定。商家已明示采用新版标准或作出符合新版标准的质量承诺的，从其明示或承诺。
### 2.2.5 标准废止
本规则列明的标准被废止且无替代标准的，平台按照本规则第2.1条和第2.2条，选择与商品及检测项目相适应的其他依据开展检测。
### 2.2.6 信息更正
本规则所列标准号、标准名称或版本与官方信息不一致的，以国家标准全文公开系统等官方渠道公布的信息为准，平台将及时更新相关内容。

# 三、检测机构
针对商品质量、性能、材质、成分、标识等品质抽检项目，本平台委托的检测机构需同时具备中国合格评定国家认可委员会（CNAS）认可资质及中国计量认证（CMA）资质。法律法规或抽检项目对机构资质另有要求的，从其规定。
# 四、判定原则
## 4.1 判定依据
各检测项目按照本规则第2条确定的检测依据进行判定。法律法规、强制性标准或其他强制性要求另有更严格规定的，按照相关要求判定。如商家在商品标题、商品详情页、商品标签、产品说明书、企业标准、质量承诺书或其他公开渠道中，作出高于国家标准的明示承诺的，按照其承诺进行判定。
检测数据的数值修约与结果判定，按对应标准规定的判定规则执行；标准未作规定的，按 GB/T 8170《数值修约规则与极限数值的表示和判定》执行。
## 4.2 总体判定
商品任一检测项目的结果不符合前述检测依据中所明示的标准要求的，即判定该商品本次抽检不合格。全部检测项目均符合要求的，判定为合格。
# 五、违规处理
平台将根据质检报告、鉴定方出具的书面鉴定报告等，针对商品不同品质问题，依据《商家【商品标识标志不合格】处置细则》《商家【商品外观/性能/安全问题】处置细则》《商家【商品材质成分不符】细则》等规则进行处置。若商家的同一商品同时存在两种或两种以上违规情形的，按照最严重项执行。
平台抽检商品的检测项目包括但不限于上述明细表中所列举的内容，平台有权根据商品特性、商品明示信息、质量安全风险以及适用的法律法规和标准，确定具体检测项目，依据《【抖音电商】商品品质抽检规范》进行检测，并根据《商家违规行为管理总则》对所有检测项目进行处理。同时，平台将根据国家及行业相关规定，不定期更新本规则及检测依据标准清单。
