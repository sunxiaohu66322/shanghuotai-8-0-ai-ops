# 第一章 概述
## 1.1 目的及依据
为营造平台内（域名为jinritemai.com）良好的购物环境， 规范商家的发货及交易行为，保障消费者权益，现依据《电子商务法》等相关法律法规的规定、《电子商务开放平台店铺服务协议》、《商家违规行为管理规则》等，特制定本规则，旨在共同维护平台的生态秩序和氛围。
## 1.2 适用范围
适用于经营需经配送完成交付商品的商家（全球购商家除外）。
## 1.3 效力级别
特别规定与一般规定不一致的，适用特别规定；新的规定与旧的规定不一致的，适用新的规定。平台规则尚无规定的，根据法律规定或相关协议处理。
# 第二章 相关定义
2.1 发货要求：消费者付款后，商家须在发货时效要求内进行发货。
另，针对蟹卡类目商品订单，消费者兑换实物商品时，商家须按照消费者选择的邮寄日期进行发货。
蟹卡类目商品：指发布或应发布在【大闸蟹卡券】类目下的商品
2.2 发货时间认定：
（1）对于物流公司有回传信息的订单，以物流公司系统回传给平台揽件记录（如物流详情为“已揽收/揽件”等状态）的时间为准；
（2）对于无物流公司回传信息的订单，以商家操作发货时间为准；若其提供物流公司发货底单显示发货时间更晚，取晚者。
2.3 发货时效要求：详见第三章
特殊说明：
商家若通过多个不同渠道承诺多个发货时效的，以有利于消费者的最短时效为准。如商家通过商品详情页、小黄车商品列表页、直播或短视频标题、口播等承诺的发货时效与商品创建时的设置发货时效不一致，平台以商家对消费者承诺的更短时效为准。
双方通过协商工具等另行约定发货时间的，以双方约定为准。

# 第四章 违规处理
平台将依据违规场景的处理细则，对商家的违规发货行为采取相应处置，具体参见：【商家-违规发货违规处理手段】实施细则。
特别说明，蟹卡类目商品订单，除蟹卡订单外，若消费者收到蟹卡后选择邮寄方式兑换实物商品，若商家蟹卡及实物商品对应的发货行为均存在违规的，平台有权依照本规则对上述履约行为同时进行处置，并赔付消费者体验损失。其中，实物兑换订单涉及违规赔付时，订单实际支付金额等同于蟹卡订单实际支付金额。
## 4.1 违规场景及处理
### 4.1.1 发货超时
定义：商家未在承诺给消费者的发货时效要求内发货。
违规处理：执行细则可参考【商家-发货超时】实施细则
### 4.1.2 缺货/无货
定义：商家自主承认缺货/无法发货/拒绝发货，或者平台或消费者无法在发货时限内联系上商家，或者商家发生其他发货违规后在规定时限内仍未发货的，相关订单/商品将被判定为缺货/无货违规。
违规处理：执行细则可参考【商家-缺货/无货】实施细则
### 4.1.3 物流轨迹超时
定义：物流轨迹超时是指商家上传物流单号点击发货后，未在规定时效内回传揽收记录，或揽收后未在规定时效内回传平台分拨记录的情形。
违规处理：执行细则可参考【商家-物流轨迹超时】实施细则
### 4.1.4 物流轨迹异常
定义：物流轨迹异常是指商家上传至后台的订单物流单号异常或对应的物流轨迹存在明显异常的情形，及/或商家上传物流单号后消费者在合理期限内未实际收到所购商品的情形。
违规处理：执行细则可参考【商家-物流轨迹异常】实施细则
### 4.1.5 欺诈发货
定义：商家未真实发货，导致物流完结时消费者未收到商品包裹的，或者实施其他欺诈行为。
违规处理：执行细则可参考【商家-欺诈发货】实施细则
### 4.1.6 其它违规发货处理措施
若使用现货预售混合发货模式的商家其预售订单产生批量投诉，或不符合预售使用门槛，平台有权取消其预售发货模式使用权限，并对预售商品进行下架操作；
若商家存在滥用或不规范使用厂家自送权限的情形，平台有权根据违规情节程度，采取最短关闭7天，最长永久关闭的处置措施，违规情形包含但不限于：
实际使用有物流轨迹信息回传的物流商发货，但商家选择“厂家自送”模式点击发货；
通过将不适用于厂家自送模式的商品发布在有权限类目；
存在物流轨迹异常（如实物未发出但系统点击发货等）、欺诈发货等发货违规行为；
使用厂家自送模式发货引发大量消费者投诉或负面舆情。
消费者实际享受的物流服务与商家/创作者承诺的不一致，平台有权依据虚假宣传相关规则进行处置，包含：
（1）商家发布或宣传的（包括商家设置的、展示的、口播的，如商品详情页、小黄车商品列表页、直播或短视频标题、口播等承诺的）物流服务方式与实际不符，包括但不限于宣传的发货/到货时效、发货模式、运费承诺、发货承运商等与物流有关的信息与实际不符等。
（2）创作者在分享推广商家的商品时，宣传的发货/到货时效、发货模式、运费承诺、发货承运商等与实际不符。违规订单由商家先行承担履约责任，如因创作者违反平台规则或跟商家的约定导致争议，商家向消费者承担责任后，举报创作者（路径：【抖店后台】-【店铺保障】-【举报中心】-【举报达人】-【异常带货】），举报成功后，可发起申诉（参见：商家申诉管理规则）。
对超长时效未签收订单（符合平台对揽收-签收环节超长时效订单定义），如果消费者发起未收到货退款申请，将默认同意退款并从商家账户自动退款；
如被处置多次后仍未及时规范发货或与消费者协商一致做退款处理的，或出现批量订单违规发货或导致批量消费者投诉的，平台有权视情况执行公示警告、商品管理（包括但不限于限制发品、商品下架、商品封禁、商品限单、商品搜索降权、商品搜索屏蔽等）、订单关闭、限制提现、推荐降权、推荐屏蔽、限制店铺权限（包括但不限于限制参与营销活动、搜索降权、搜索屏蔽、冻结货款、停止结算、延长结算账期、订单限制、停业整顿、限制广告投放等）、扣除违约金、提高保证金应缴额、扣除违规所得货款、清退店铺、关联店铺/账号处理、赔付消费者、限制精选联盟相关权限、禁止投流、禁止上新、禁止上架、要求使用抖音电子面单及平台认为必要的其他处理措施。
违规发货行为是商家评级的负向评价指标，相关违规判定记录将同步计算在商家评级分值中，影响商家评级分值，进而影响商家在平台的各项权益，如极速发货产品使用权益、大促活动等；
平台对以上违规行为的处理，并不免除商家作为销售者应当承担的法律责任，若消费者依法发起索赔，商家应自行与消费者协商解决，并承担相应的法律责任。
商家就发货违规与消费者单方协商所作出的赔付承诺，由商家自行和消费者解决，平台仅根据相关发货违规场景的执行细则标准执行，不受商家对消费者的单方承诺影响。
## 4.2 除外场景
以下场景，不计入相关的违规处理：
消费者滥用发货规则或购买行为不是为了满足生活消费所需的；
商品本身或信息涉嫌违法违规的，为保障消费者权益，平台要求商家立即停止发货的；
因自然灾害、会议赛事等不可抗力特殊情形导致商家无法按照约定时间发货；
平台官方发起的促销活动及特定节假日等需要调整发货时效要求的，具体以平台通知或公告的发货时间为准。
# 第五章 商家申诉
商家收到违规通知时，若不认可该违规处理，可在收到违规处理通知的7个自然日内发起违规申诉，未在申诉时效内进行申诉处理的，视为商家认可违规处理，具体要求可查看《商家申诉管理规则》。申诉路径为【店铺-店铺保障-申诉中心】。平台将在收到申诉申请的5个工作日内给予商家申诉结果。
注：商家发起申诉并不影响平台已经做出违规处理决定的效力和执行、公示。仅在平台对商家发起的违规申诉做出申诉成功的认定后，平台会撤回相关处理决定。
# 第六章 争议处理
6.1 若因商家发货问题导致消费者发起交易纠纷申请的，商家需积极配合处理，平台将基于法律法规的规定、协议的约定以及消费者和商家提供的证据材料，依据本规则及《售后争议处理总则》做出判断并要求商家承担相应赔付责任。
6.2 如商品实物或信息涉嫌违法违规的，为保障用户权益，平台有权要求商家立即停止发货，订单不支持赔付。
# 第七章 附则
7.1 【生效时间】本规则于2020年09月02日首次生效，于2026年7月8日修订并生效实施。
7.2 平台有权对本规范进行不定期修订，并根据法律法规的规定执行公示程序。若修订内容涉及交易规则的，则将根据法律法规规定另行执行征求意见程序，公示期结束后，本规范内容即告生效。若商家不同意修订后的规范的，可通过平台指引申请停止使用平台服务。
7.3 平台商家的相关行为，发生在本规则生效之日或修订之日以前的，适用当时的规则。发生在本规则生效之日或修订之日以后的，适用本规则。
