# 一、违规定义
商品核心信息误导，指商家发布的商品中存在容易导致消费者误解的信息，如商品关键信息不一致、规格信息不规范、或存在其他混淆性信息等。
# 二、违规情形
包括但不限于：
（1）关键信息不一致：即商品发布的关键信息之间存在相互不一致，如交易平台、售卖主体、商品属性、商品规格、发货模式、承诺发货时效、七天无理由退换货等信息存在不一致问题；
（2）规格信息不规范：如规格数值异常（一箱苹果，净重填写1-1g、1个）、将跨品牌/跨类目/跨系列等与商品主体无关信息或无关联商品绑定在同一SPU下、库存为0导致无法购买、规格描述不规范等可能引发消费者误解的行为（如描述“下6单得30双”但未明确1单或其他单数的到手数量，引发消费者产生1单得30双的误解）；
（3）冒用旗舰店名义：指商品信息中宣传店铺类型与实际不一致，如非旗舰店，在主图、标题等宣传旗舰店信息；
（4）与非标准尺寸物体做对比：如生鲜食品类目的商品，通过与非标准尺寸物体（如人体部位手掌、脸、手臂等）做对比的方式展示或说明商品大小，易导致消费者对商品实际尺寸产生误判，形成较高心理预期。

# 三、违规处理
| 违规程度 | 处置措施 |
| --- | --- |
| 首次及二次违规 | 商品下架/重置移除违规信息 |
| 三次及以上违规 | 商品封禁 |
| 多个商品违规或违规商品销量大 同时存在遮挡/变形/规避信息行为 违规行为已对平台及消费者造成不良影响的 涉及舆情、消费者投诉等情形 | 商品封禁 冻结违规商品货款并停止结算30天 |
# 四、商家申诉
（1）申诉路径：商家不认可该违规处理，可以登录抖店后台，通过以下路径操作申诉：
抖店电脑端：【抖店后台-店铺-申诉与举报-申诉中心-违规申诉-可申诉】
抖店APP端：【抖店APP-首页-违规管理-违规列表】
（2）申诉时效：商家需要在收到违规通知后7天内发起申诉，平台会在申诉页面展示申诉时间倒计时，超时将无法申诉。提交申诉后，平台将会在1-5个工作日内给出申诉审核结果，若申诉过程中，平台需要商家补充申诉材料，会将申诉暂时退回，商家可在申诉中心-驳回待补充页面查看，并点击【申诉】补充材料，时效为72小时，超时未补充则申诉失败；
（3）申诉举证材料：
若您不存在此类违规行为，请根据实际情况上传举证材料，平台会根据相关信息复核。
