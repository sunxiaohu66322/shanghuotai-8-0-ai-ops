# 一、平台导向
抖音电商致力于成为“用户发现丰富好物的首选平台”，践行“让用户高效发现好物，享受丰富美好生活”的使命。抖音电商认为只有保障商品品质、提供优质消费体验，才能赢得消费者信任，减少因商品劣质、体验不佳而产生的消费困扰。因此我们倡导商家坚持品质经营，优化商品品质。
# 二、违规定义
“综合认定商品/商家品质差”是指平台基于消费者反馈、商家/商品经营行为及数据等信息，综合研判认定商家/商品存在品质差问题或存在品质问题风险。其中：
消费者反馈来源，包括但不限于：商品评价、售后反馈、消费者投诉等；
商家/商品经营数据，包括但不限于：差评率、好评率、品质问题商品退货量、品质问题商品退货率、品质问题反馈订单占比、品质问题商品订单数、品质问题商品订单占比、商品体验分；
综合研判认定商家/商品存在品质差问题的判定标准，包括但不限于：商品或商家的经营数据差于同类目商品或商家的平均水平且具有一定距离，或存在一定消费者负面反馈，则认定为商品品质差违规或商家品质差违规。
# 三、违规处置及影响
【综合认定商品/商家品质差】的违规处置如下：
（1）平台结合消费者反馈、商家/商品经营行为等信息，综合研判认定商品/商家存在品质问题风险的，平台将采取以下措施，避免消费者权益或购买体验、平台交易秩序受损。

# 四、常见违规类型
包括但不限于：
描述与售卖不一致（商品名称、规格、成分、材质、产地、年份等）；
做工瑕疵；
商品破损/污损/变形；
商品变质/异物；
有效期问题；
异味问题；
食用/使用商品后出现身体不适；
以残次品或处理品冒充新品售卖；
产品外观/使用性/功能出现异常或缺陷问题；
商品标识标志不合格；
产品不具备应有使用功能或影响消费者购买或使用体验的情形。
# 五、经营建议及申诉
## 5.1 经营建议
建议商家围绕商品管控、数据优化等环节做好日常运营管理。
（1）商品品质
提升生产工艺标准，减少做工粗糙/质量不好等问题；
确保实物与宣传信息一致，避免尺寸/材质/做工不符等情况；
针对食品类商品，严控效期与储存条件，优化包装并选用优质物流，降低发霉/腐烂/变质等问题。
（2）运营指标关注
定期分析商品差评/品质退货等核心原因，针对性优化商品质量，减少负面反馈与客诉。
## 5.2 申诉
（1）申诉路径
路径1：抖店后台-店铺-申诉与举报-申诉中心-违规申诉
路径2：抖店后台-违规管理-违规处置-违规详情-去申诉
（2）申诉处理时效与处理结果
商家需要在收到违规通知后7天内发起申诉，平台会在申诉页面显示申诉时间倒计时，超时将无法申诉。平台收到商家提起的申诉后，将在1-5个工作日内尽快审核商家提交的申诉材料并反馈相应处理结果。若申诉成功，则对应的处理不成立；若申诉不成功，则对应的处理成立。详见《商家申诉管理规则》。

一、案例背景 汉堡王自2021年5月以来在抖音平台长期稳定自播，不断优化货品，致力于将美味、高品质、价格合理的汉堡带给每一位用户。但是通过商城数据诊断发现，对比其他相似商家自身搜索曝光流量偏低、店铺页曝光和转化率较低。汉堡王期望提升在抖音商城场景的表现，通过提升曝光和点击转化，进而提升品牌的GMV数据。 二、诊断结论及策略方向 诊断结论： 搜索：短视频、商品卡整体曝光点击率低于相似商家，短视频和商品卡成交率较低。 店铺：店铺整体流量较相似商家低，商品曝光点击率较低。 商城推荐：商城曝光和曝光点击率低于相似商家。 核心策略： 前期阶段优化商城基建，8月底筹备百万宠粉日打造内容场+中心场+营销场的全域狂欢。 三、商城优化动作及效果 通过专项优化，汉堡王抖音商城GMV+6%（VS全店占比+4%） 搜索场景：搜索GMV提升+5%，商品曝光提升+45% 店铺场景：店铺GMV提升+13%，商品曝光提升+5% 商城场景：频道及活动页GMV提升+31%，商品曝光提升+361% 亮点动作1：搜索场景优化 搜索GMV提升+5%，商品曝光提升+45% 商品标题添加品牌词、行业热词及营销词，虚拟卡券标题直接分
