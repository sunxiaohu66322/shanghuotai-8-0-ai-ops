# 一、违规定义
骚扰他人，指商家辱骂、威胁、诽谤、诋毁他人，或使用任何引起他人不满的字句，或采取恶劣手段对他人实施骚扰等妨害他人合法权益的行为。
# 二、违规处置
商家涉嫌辱骂骚扰等违规事实成立的，平台有权根据违规程度采取对应的处置措施：
| 违规程度 | 处置措施 |
| --- | --- |
| 消费者向平台投诉或平台识别到商家存在辱骂、骚扰他人情形； | 警告 |
| 两次以上辱骂他人或多次发生其他骚扰他人行为； | 每次违规扣除违约金500元（冻结15天后执行） |
| 多次发生辱骂他人、严重骚扰他人的行为； 或商家未经他人允许私自上门、邮寄恶心物品等；或商家骚扰辱骂行为严重影响他人正常生活、造成严重恶劣影响等。 | 店铺清退，扣除违约金6000元（冻结15天后执行） |
消费者反馈被商家威胁、短信/电话骚扰、网暴、辱骂等，经平台判定投诉成立的，平台将扣除商家货款/保证金用于向消费者赔付，赔付标准为每次300元现金，滥用上述规则发起赔付申请的，平台将不支持赔付。
# 三、违规情形
包括但不限于：
辱骂：商家通过电话、短信、IM、评论、举证等方式对他人使用含有侮辱、谩骂、诅咒、人身攻击等不文明用语，或引起他人不满的用语。包括但不限于：
（1）直接对他人进行人身攻击，包含使用文字/拼音/首字母/英文/外号/同音词/近音词/表情/表情包/图片/方言/动物指代词汇/口头禅/网络用语等方式；
（2）间接对他人进行人身攻击，包含诅咒家人、嘲讽他人地域/文化水平/智商、用不同形式辱骂等方式。
威胁：商家让他人产生恐慌、不安全等感受的任何内容、语言或者行为，威胁的内容包括但不限于他人的隐私、名誉、住址、财产及人身安全；
频繁发送消息造成打扰：商家通过包括但不限于短信、邮件、飞鸽、精选联盟等方式向他人频繁、大量发送消息，对他人造成骚扰等；
邮寄让人产生反感的物品：包括但不限于商家向他人邮寄冥币、寿衣等让人产生反感的物品等行为；
无故上门：商家未经他人允许私自上门，造成他人反感或恶劣影响，包括但不限于商家未经他人允许私自上门、无明确诉求前往平台办公区域影响工区秩序等。
# 四、“他人”的定义
包括但不限于与商家产生或可能产生交易的创作者、消费者、其他商家及其亲属、朋友、工作单位人员以及平台工作人员等。
# 五、平台处置
包括但不限于：
商家自认；
平台通过内容识别、人工巡查/审核等方式发现存在骚扰行为；
被骚扰方提供有效证据证明骚扰行为属实等。
# 六、受到骚扰需提交的证据
被骚扰方投诉时可以提交能反映真实情况的相关凭证，包括与商家之间的飞鸽聊天记录截图、电话通话记录详情单、手机短信截图、骚扰物品的快递单据等。
# 七、判定消费者投诉成立但不支持赔付的情形
出现下述任一情形的：
（1）消费者与商家均存在骚扰、辱骂等相关行为，但消费者先行出现前述行为，且商家未有促使消费者情绪升级、矛盾激化等行为的。如：商家未有激烈（系指频次、程度等判断）回骂、向消费者邮寄商品进行恐吓、威胁上门等行为；
（2）经平台认定，消费者在交易前不以成交为目的，交易后不以解决售后争议为目的，滥用本规则以实现其牟利意图的。如，出现挑衅、故意激怒商家等行为，诱使或致使商家违规。
# 八、商家申诉
（1）申诉路径：商家不认可该违规处置，可以登录抖店后台，通过以下路径操作申诉：
抖店电脑端：【抖店后台-店铺-申诉与举报-申诉中心-违规申诉】
抖店APP端：【抖店APP-首页-违规管理-违规列表-可申诉】
（2）申诉时效：商家需要在收到违规处置的通知后7天内发起申诉，平台会在申诉页面展示申诉时间倒计时，超时将无法申诉。提交申诉后，平台将会在1-5个工作日内给出申诉审核结果。
（3）申诉举证材料
若您不存在恶意骚扰行为（如辱骂、威胁、频繁联系邀好评/改评价、诱导好评/改评价承诺不履行、发送违规广告导流消息、邮寄反感物品、私自上门等），请在【申诉原因】处选择【不存在恶意骚扰行为】，此场景无需上传举证材料，平台根据违规判定依据复核。
