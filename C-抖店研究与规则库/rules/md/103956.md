# 第一章 概述
# 1.1 适用范围
适用于抖音电商平台商家（即时零售、全球购商家除外）
## 1.2 体验分定义
商家体验分是反映店铺综合服务能力的重要指标，该指标覆盖了用户消费全链路，可为商家提供店铺服务能力诊断和改善所需的数据支持。用户消费体验好的店铺分数更高，可获得更多的平台支持。
# 第二章 实施细则
## 2.1 考核对象
### 2.1.1 考核店铺
根据近30天有效支付订单数将商家区分为成长阶段和正式阶段分别设置体验分考核方案，具体如下：
| 商家阶段 | 标准 | 体验分考核方案 |
| --- | --- | --- |
| 成长阶段 | 近30天有效支付订单数＜30单 | 具体见【2.2成长阶段】 |
| 正式阶段 | 近30天有效支付订单数≥30单 | 具体见【2.3正式阶段】 |
### 2.1.2 考核订单
本规则中订单均指有效支付订单，赠品、福袋、低价、秒退订单以及异常订单不纳入考核范围。特殊说明：扣分项不限制订单类型，全部订单均纳入考核。
## 2.2 成长阶段
### 2.2.1 计算规则
基于店铺的入驻时间，在店铺完成对应出分任务后次日，即可获得成长阶段体验分70分；商家店铺类型为个人店时，不适用成长阶段体验分计算规则。
| 店铺入驻时间 | 体验分出分任务 |
| --- | --- |
| 入驻时间≤90天 | 售卖中商品数≥1 |
| 入驻时间＞90天 | 售卖中商品数≥1且近30天有效支付订单数≥1 |
| 注：上述售卖中商品的商品类型不包含闪购商品、非卖赠品、奖品商品 |  |
### 2.2.2 特殊说明
当店铺近30天内存在以下任一情形时，成长阶段体验分降低至60分：
商家存在消极服务/消极售后等影响消费者体验的行为，包含但不限于设置异常售后地址、拒开发票等；
商家存在通过刷单刷评、炒信作弊等非正常手段提高体验分等行为；
商家存在虚假宣传、欺诈发货、出售/分享假冒或盗版商品；
以下表格中存在任一体验指标不符合平台合格标准（体验指标的合格标准详见抖店-商家体验分页面）
| 维度 | 体验指标 | 指标定义 | 考核周期 |
| --- | --- | --- | --- |
| 商品体验 | 商品差评订单数 | 近30天物流签收订单中消费者商品评分为1星或2星的差评订单数 | 近30天物流签收订单 |
|  | 商品品质退货订单数 | 近30天物流签收订单中因商品品质原因售后的订单数 注：取用户首次申请售后原因 | 近30天物流签收订单 |
| 物流体验 | 平均揽收时长 | 平均揽收时长 = 近30天揽收订单的揽收总时长/ 近30天揽收订单数 *注： 订单揽收时长计算：指订单从消费者支付到物流商揽收的时长； 在当日18点-次日6点间支付的订单，从次日6点开始计算揽收时长； | 近30天揽收订单 |
|  | 运单配送时效未达成运单数 | 近30天未达成配送线路时效要求，或存在物流轨迹异常运单数 | 近30天物流应签收运单 |
|  | 商品/包装破损退货订单数 | 近30天支付订单中因商品/包装破损售后的订单数 *注：取用户首次申请售后原因 | 近30天支付订单 |
| 服务体验 | 售后平均审核时长 | 售后平均审核时长 = 近30天退款成功售后单的售后审核总时长 / 近30天退款成功售后单数 *注： 1）考核售后单类型：已发货退款、退货退款 2）售后审核时长： ——已发货退款：消费者发起退款申请，到商家或系统同意退款给消费者的时间 ——退货退款：消费者发起退货退款申请，到商家或系统同意退货的时间 3）在当日23点-次日8点间发起的售后单，从次日8点开始计算售后审核时长 | 近30天退款成功售后单 |

|  | 飞鸽会话不满意数 | 近30天消费者评价人工客服为不满意（1-3星）的会话数 *注：只考核发起时间在8:00:00-22:59:59期间的人工客服会话 | 近30天人工客服会话 |
|  | 平台求助数 | 近30天消费者升级求助平台订单数 注：消费者升级求助平台订单，指有售后仲裁的订单，或消费者咨询商家人工客服后因同一诉求咨询平台客服、向平台投诉的订单 | 近30天求助商家订单 |
## 2.3 正式阶段
### 2.3.1 考核指标
正式阶段商家体验分为百分制，最低为0分，最高为100分，由商家近30天内的【商品体验】、【物流体验】及【服务体验】三个评分维度加权计算得出，具体考核指标及考核周期如下：
| 评分维度 | 细分指标 | 指标定义 | 考核周期 |
| --- | --- | --- | --- |
| 商品体验 | 商品综合评分 | 商品综合评分 = 近30天物流签收订单中商品评分总和/ 近30天物流签收订单中有商品评分的订单数 | 近30天物流签收订单 |
|  | 商品品质退货率 | 商品品质退货率 = 近30天物流签收订单中因商品品质原因售后的订单数/ 近30天物流签收订单数 *注：取用户首次申请售后原因 | 近30天物流签收订单 |
| 物流体验 | 平均揽收时长 | 平均揽收时长 = 近30天揽收订单的揽收总时长/ 近30天揽收订单数 *注： 订单揽收时长计算：指订单从消费者支付到物流商揽收的时长； 在当日18点-次日6点间支付的订单，从次日6点开始计算揽收时长； | 近30天揽收订单 |
|  | 运单配送时效达成率 | 运单配送时效达成率 = 近30天达成配送线路时效要求的运单数/近30天应达成配送线路时效要求运单数 *注：如运单存在物流轨迹异常，则该运单计为不达成 | 近30天物流应签收运单 |
|  | 商品/包装破损退货订单率 | 商品/包装破损退货订单率 = 近30天支付订单中因商品/包装破损售后的订单数/ 近30天支付订单数 *注：取用户首次申请售后原因 | 近30天支付订单 |
| 服务体验 | 售后平均审核时长 | 售后平均审核时长 = 近30天退款成功售后单的售后审核总时长 / 近30天退款成功售后单数 *注： 1）考核售后单类型：已发货退款、退货退款 2）售后审核时长： ——已发货退款：消费者发起退款申请，到商家或系统同意退款给消费者的时间 ——退货退款：消费者发起退货退款申请，到商家或系统同意退货的时间 3）在当日23点-次日8点间发起的售后单，从次日8点开始计算售后审核时长 | 近30天退款成功售后单 |
|  | 飞鸽平均响应时长 | 飞鸽平均响应时长 = 近30天工作时间消费者与商家飞鸽对话轮次的回复时长之和 / 近30天工作时间人工咨询对话轮次总数 *注： 1）只考核发起时间在8:00:00-22:59:59期间的人工客服会话； 2）若用户发消息后，客服未回复，本轮回复时长记为10分钟； 3）若用户发消息后，客服回复存在消极敷衍等情形，本次回复记为无效回复，若客服后续有有效回复，则本轮回复时长记为「用户发消息到客服有效回复」的时长；若客服后续无有效回复，则记为客服未回复，本轮回复时长记为10分钟。 | 近30天人工客服有效会话量 |
|  | 飞鸽会话不满意率 | 飞鸽会话不满意率 = 近30天消费者评价人工客服为不满意（1-3星）的会话数 / 近30天有人工客服评价会话数 *注：只考核发起时间在8:00:00-22:59:59期间的人工客服会话 | 近30天人工客服会话 |
|  | 平台求助率 | 平台求助率 = 近30天消费者升级求助平台订单数 / 近30天消费者求助商家订单数 注： 1）消费者求助商家订单：指消费者发起售后申请或咨询商家人工客服的订单 2）消费者升级求助平台订单：指有售后仲裁的订单，或消费者咨询商家人工客服后因同一诉求咨询平台客服、向平台投诉的订单 | 近30天求助商家订单 |
### 2.3.2 计算规则
正式阶段商家体验分 = 商品体验得分*该项权重 + 物流体验得分*该项权重 + 服务体验得分*该项权重 + 加分项 - 扣分项
（1）商品体验：根据近30天的商品综合评分和商品品质退货率在各行业的表现计算得出，最低分50分，最高分100分。
（2）物流体验：根据近30天的平均揽收时长、运单配送时效达成率和商品/包装破损退货订单率在各行业的表现计算得出，最低分50分，最高分100分。
（3）服务体验：根据近30天的售后平均审核时长、飞鸽平均响应时长、飞鸽会话不满意率和平台求助率在各行业的表现计算得出，最低分50分，最高分100分。
（4）加分项：当店铺近30天内存在以下任一情形时，平台将对店铺的商家体验分给予一定加分(以下场景累计加分，但同一场景在近30天内仅可获得 1 次加分)：
| 加分项 | 指标定义 | 加分标准 |
| --- | --- | --- |
| 明日达订单占比 | 明日达订单占比= 近30天物流签收订单中完成明日达的订单数/ 近30天物流签收订单数 | 明日达订单占比>=20%，体验分单次加5分，近30天累计不超过5分； |
| 退换货运费险 | 近2天均开通退换货运费险，且近30天支付订单中，有1单退换货运费险订单 | 体验分单次加2分，近30天累计不超过2分； |
| 大件退换货运费险 | 近2天均开通大件退换货运费险，且近30天支付订单中，有1单大件运费险订单 | 体验分单次加2分，近30天累计不超过2分； |
| 上门安装 | 如商家开通上门安装权益，且近30天支付订单中，指定范围内(限定类目和实付价格范围，见下文)上门安装订单数>=50单，且指定范围内上门安装订单占比>=30% “指定范围”详见： 上门安装限定类目和实付价格公示 。 上门安装订单占比= 近30天指定范围内上门安装订单数 / 近30天指定范围内支付订单数。 | 体验分单次加2分，近30天累计不超过2分； |
（5）扣分项：当店铺近30天内存在以下任一情形时，平台将对店铺的商家体验分执行扣分处置(以下场景累计扣分)：
如商家设置异常售后地址，每次扣2分，近30天累计不超过10分；
如商家拒开发票，每次扣2分，近30天累计不超过10分；
如商家存在通过刷单刷评、炒信作弊等非正常交易手段违规提高体验分的，一次性扣10分，近30天累计不超过10分；
如商家虚假宣传，一次性扣10分，近30天累计不超过10分；
如商家欺诈发货，一次性扣10分，近30天累计不超过10分；
如商家出售/分享假冒或盗版商品，一次性扣10分，近30天累计不超过10分。
若商家开通偏远地区物流服务且近30天偏远中转签收且无售后的订单数≥1时，物流体验加分3分（物流体验最高为100分），具体可见偏远地区物流服务规则。
如商家违反法律法规、平台规则采取提供虚假凭证等不正当方式，主观恶意干扰商家体验分考核，为保证分数考核计算的客观公正，平台有权视具体情节对商家体验分采取干预措施，干预方式包括不限于一定时限内商家体验分屏蔽（即不显示商家体验分）、设定分数上限等。
### 2.3.3 考核权重
根据行业特性，不同行业的商品体验、物流体验和服务体验的考核权重会存在差异。同时，部分行业会基于店铺类型是否为旗舰店，进行拆分考核：
（1）店铺类型为通用时，说明该行业全部商家不区分店铺类型统一考核；
（2）店铺类型为旗舰，说明该行业全部旗舰店商家统一考核，包括官方旗舰店和旗舰店商家；
（3）店铺类型为非旗舰，说明该行业全部非旗舰店商家统一考核，具体包括专卖店、专营店、企业店、个体店、个人店等。

# 第三章 数据展示说明
## 3.1 数据更新周期
商家体验分每天上午进行分数更新，具体时间以抖店后台展示的更新时间为准。
## 3.2 商家端展示
3.2.1 展示路径
商家可通过【抖店后台】-【店铺】-【商家体验分】查看商家体验分数据情况，并可查看【分数概况】、【任务概况】、【权益概况】、【指标诊断】和【全部指标】等模块。
3.2.2 分析诊断
（1）正式阶段商家可通过首页【全部考核指标】模块，查看所有考核指标的数据表现、变化趋势等；
（2）正式阶段商家可点击【全部考核指标】模块指标名称，进入对应指标的诊断详情页，查看近30天指标趋势，以及商品、物流、服务更细维度的诊断分析。
## 3.3 消费者端展示
3.3.1 成长阶段分数展示

# 第四章 应用场景
商家体验分应用于平台营销活动提报、精选联盟准入、千川投放等场景，具体应用方式和门槛参考对应规则：
4.1 【千川投放限制】商家体验分低于管控要求，将禁止投放；详见《巨量千川准入&管控规则指引》
4.2 【活动提报】商家体验分达到活动报名门槛时，可报名参加平台特定营销活动；详见《平台营销活动基础规则》
