## 1. 登录链路（已跑通）

- ego 必须带 `--remote-debugging-port=9224 --user-data-dir=F:\ego-ud-link --profile-directory="Profile 5"` 启动；
  `Profile 5` = 「您的 Tabbit」，是当前有抖店登录态的那个 profile（`Local State` 里 `profile.last_used=Profile 5`）。
- **踩坑（重要）**：ego 若不指定 `--profile-directory`，会落到 `Profile`（0 个 cookie），表现为"明明登录过却跳登录页"。
- 邮箱登录页结构：`input[name=email]` + `input[name=password]` + 一个 `input[type=checkbox]`（即"登录即代表同意"，必须勾）；
  切换标签是 `div[class*=switch-button]`，文案「邮箱登录」，已选中时 class 带 `true`。
- **成功判据**：URL 从 `/login/common?...` 跳到 `/ffa/g/list`，标题变「商品管理」，页头出现店铺名 `LZL乐群云家具专卖店`。

## 3. 建品页实测（AI 建品）

`/ffa/g/create` 结构：
- 文件上传控件两个 `input[type=file]`：`[0]` accept=`.jpg,.png,.jpeg,.csv,.xls,.xlsx` multiple=true（主入口）；`[1]` 无 accept。
- 按钮：`本地上传 / 图库选择 / 下一步，生成商品`；另有 `返回旧版`。
- 文案确认「至少包含一张不小于 600*600 的商品图」。

**用 CDP `DOM.setFileInputFiles` 投递 4 张（3 主图 + 1 详情）**：
```
已上传 4
image_3da0d718bbce.jpg        ✅ 上传成功
image_635d76352013.jpg        ❌ 上传失败
image_af26132d18c8.jpg        ❌ 上传失败
image_50e4f63db3f1.jpg        ❌ 上传失败
提示：素材库容量已满，请至电脑端抖店【商品素材-素材库】删除素材。
```
旧版入口（`/ffa/g/create?entrance=create`、`?cid=1000004588`）**同样报"素材库容量已满"** —— 说明这是账号级存储配额，
不是新/旧版差异，也不是我这边脚本的问题。

## 4. 硬卡点（必须用户决策）

**素材库容量已满 ⇒ 任何图片上传都失败 ⇒ 无法建商品 ⇒ 无法验证送货脚本。**

不是可绕的：新版、旧版、投 1 张、投 4 张，全部同一句错误。

两条出路，选一条：
- **A 清素材库**（`商品素材 → 素材库`，删旧素材）—— 破坏性，删掉的素材可能被在售商品引用，需先看引用。
- **B 升配额 / 加购存储** —— 非破坏性，但要看平台政策与费用。
