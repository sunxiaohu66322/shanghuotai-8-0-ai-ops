## 1. 原版的「改库存」流程（bundle 结构 + 实测推断）

从解包结果里读到的入口结构（字段名逐字）：

```
批量修改 > 改库存
  商品选择：列表勾选 / 按 ID 粘贴 / 按分类筛选
  修改方式：设为 / 增加 / 减少
  库存值：整数
  提交前确认弹窗（件数 × SKU 数）
  任务中心：创建 → 排队 → 执行中 → 成功 / 失败（带逐 SKU 错误）→ 重试
```

**与本项目最关键的一条差异（本轮实测撞出来的）**：

原版是**多店 ISV 体系**——它自己攒着一批已上架商品的 access_token，改库存直接调微信
`/channels/ec/product/stock/update`（快速接口）。这个接口**只对已上架商品有效**。

## 2. 本轮实测到的官方硬约束（真数据、可复现）

测试商品：`10001792717065`（茶桌，草稿态 status=6，12 个 SKU）

### 2.1 快速接口对草稿品必失败

```
POST /channels/ec/product/stock/update   diff_type=1  num=999
→ 逐个 SKU 报「商品不存在 rid: 6adf7a27-01841692-43d72cf7」
```

**结论**：`stock/update` 只认已上架商品。店里有草稿品（status=0/6/13）时，改库存这条链**必须有第二条路**。

### 2.2 第二条路不能只传 skus

```
POST /channels/ec/product/update   {product_id, skus:[{sku_id, stock_num ...}]}
→ 6600016 类目错误，请检查类目是否正确
```

**结论**：官方 `product/update` 要求完整必填结构（类目等）。**必须提交整对象**——先读 `edit_product`、在内存里换 `stock_num`、再整本递回去。这与上一轮 `run_edit` 撞到的坑完全同源。

### 2.3 本地修法（app.py `do_stock`）

```
1) 先按 mode 算出每个 SKU 的新库存（set / add / sub，各自基于当前值，下限 0）
2) 逐 SKU 试 stock/update（快速、便宜）
   — 全成 → 「快速接口」返回
   — 报「商品不存在」/ 40009 / 47001 → 置 need_fallback
3) 兜底：读到的 edit_product 整对象，只换 skus[].stock_num → product/update
```

预览（dry_run）同步改成**逐 SKU 显示**：
`预览：12 个 SKU，库存 [298, 298, 296] → [999, 999, 999]（合计 3577 → 11988）｜未上架商品走整对象更新`

## 3. 端到端验收（真接口、真读回、真还原）

| 步 | 操作 | 结果 | 独立读回核对 |
|:--|:--|:--|:--|
| 1 | 基线 | — | `[298,298,296,298,299,298...]` 合计 3577 |
| 2 | `dry_run` 预览 | ✅ 只算不写 | 预览数字与基线一致 |
| 3 | `set=999` | ✅ 「整对象模式」 5891ms | 读回 `[999×12]` |
| 4 | `add=3` | ✅ | 读回 `[1002×12]`（走 `/api/product?slim`，与 UI 同一数据源） |
| 5 | `set=298` 还原 | ✅ | 读回 `[298×12]` **合计 3576 ≠ 原 3577** ← 抓到坑 |
| 6 | 逐位精确还原（按 CSV 源行） | ✅ | `[298,298,296,298,299,298,295,300,300,300,300,295]` 合计 **3577**，逐位一致 |

**第 5→6 步是本轮最值钱的一条**：`set` 是"抹平"语义，用它还原会把原本各 SKU 不同的库存变成一个值。
**改库存的还原必须按逐 SKU 原值写**，不能用统一值——已在验收里验证到能精确恢复。

### 错误处理与重试

- 单件失败不影响其他商品（`ThreadPoolExecutor` 逐件 try/except，`/api/batch` 返回逐件结果）
- 每次批量写都落 `data/tasks.jsonl`（op/mode/value/dry_run/total/ok/fail/items 含逐件错误原文）
- 失败可原参数重跑（`set` 幂等；`add` 重跑会叠加 —— UI 上已要求先预览）
