## 二、进程模型与真实运行约束（本轮踩到的）

| 事实 | 后果 / 要求 |
|:--|:--|
| `ThreadingHTTPServer` + `run_batch` 用 `ThreadPoolExecutor(4)` | 批量任务在**本进程内**跑；进程被杀任务即丢，无恢复 |
| 服务是 `Start-Process` 起的 shim 拉起真身 | **重启不能只杀记录的 PID**：本轮曾出现 4 个 `python app.py` 同时存活，杀掉后端口被残留进程抢走 → **新代码不生效，HTTP 仍返回旧逻辑结果** |
| 判据 | 用 `Get-NetTCPConnection -LocalPort 9191` 看**监听者 PID**，不是看自己起的 shim |
| 前端 JS 无构建、靠 `index.html?v=N` 做缓存失效 | 改 `web/*.js` 必须同时 bump `?v=`，否则浏览器仍跑旧 JS |
| 凭据 | `config.json` 明文存 appid/secret；token 缓存 `.cache/token_<appid>.json`（过期前 300s 刷新）|

## 四、数据与存储

**本项目不落业务数据库**（刻意设计：避免"本地状态与微信真值不一致"的假状态）。`data/` 内容：

| 文件 | 作用 | 一致性风险 |
|:--|:--|:--|
| `tasks.jsonl` | 每次批量操作的流水（op/mode/value/dry_run/total/ok/fail + **逐件错误原文含 rid**） | 追加写，无并发锁；崩溃可能留半条 |
| `imgcache.json` | 外链图片 URL → 微信 `mmecimage.cn` 链接，md5 命名，**同图只传一次** | 写盘走 `.tmp` + `os.replace` 原子替换 |
| `yunku/*.json` | 商品**全量 JSON 备份**（原版云库的本地替代） | 只有备份，**回滚未实现** |
| `exports/*.csv` | 导出产物 | — |
| `.cache/cats.json` | 25 MB 全量类目树，TTL 86400s | 过期自动重取 |

商品/订单/优惠券/运费模板等一律**实时读官方接口**，不做本地副本。

## 五、已核实的官方接口硬约束（写代码必须守，全部实测撞出来的）

| # | 约束 | 错误码 | 应对 |
|:--|:--|:--|:--|
| 1 | **`product/update` 不接受只传改动字段**，必须整对象（含类目等必填） | `6600016 类目错误` | 读 `edit_product` → 内存改 → 整本回传（`run_edit`/`do_stock`/`do_price` 三条兜底已统一） |
| 2 | **`stock/update` 只对已上架商品有效**，草稿/审核中一律「商品不存在」 | `商品不存在` / 40009 / 47001 | 自动降级整对象更新 |
| 3 | **`img/upload` 必须带真实 width/height**，缺省或 0 直接拒 | `10020055 参数有误` | `WxShop.img_size()` 纯标准库解析 PNG/JPEG/GIF/BMP（JPEG 魔数是 2 字节 `\xff\xd8`，写 `[:3]` 会静默返回 (0,0)） |
| 4 | `product/add` 要求类目必填属性齐全 + 必须支持 7 天无理由 | `6600045` ×N + `6600079` | 建品时把 CSV 属性列拆进 `attrs`，并带 `extra_service.seven_day_return=1` |
| 5 | 价格字段是 **分（int）**，`stock_num` 不能是浮点 | `47001 data format error` | `to_fen()` 统一转换，容错 `549.00~959.00` 取低值、`￥12.5元` 抠数字 |
| 6 | SKU `attr_value` 为空会报空指针 | 上游导出常见 | 归一器把「N/M 个 SKU 名称为空」标为不可建并拒绝 |
| 7 | `order/list/get` 必须带 `create_time_range` | — | 默认最近 7 天 |
| 8 | 商品列表 `total_num` 不可靠，翻页只认 `next_key` | — | `_all_ids()` 按 next_key 翻到空 |
| 9 | `data_type=2` 才读得到未上架商品，且结构放在 `edit_product` 不是 `product` | — | 统一走 `_p()` 取 |

## 六、接口面（39 个端点，`/api/` 前缀）

- **读**：`health / shop / products / product / categories / category / freight / coupons / orders / tasks / editSpec / overview / uploads / photo/{status,roots,list,file,out} / diagnose / yunku / exportRecords / config`
- **写**：`upload / product/{add,update,status,delete} / batch / edit / patch / yunku/{save,remove} / export / photo/{inpaint,batch,detect}`
- **导入链**：`import/preview`（只解析）→ `import/normalize`（归组+校验，出 blocks）→ `import/create`（`dry_run` 试算 / 真建草稿）

`GET /api/editSpec` 让前端按规格自动渲染表单，避免 35 个编辑页各写一套 UI（本轮补测的 13 个动作都靠它）。
