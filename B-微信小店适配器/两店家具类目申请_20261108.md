> 目标：微信 A（欢轴家居 `wx6ff10d09ff0ee823`）、微信 B（崇耿 `wxfc4e24a2ebcb2b0a`）两店分别申请「家具类相关、未开通、符合保证金规则」的经营类目。**本轮纠正：不做抖店**。

## 1. 走 API 还是走后台 · 为什么

**结论：走官方 API，不进网页后台。**

- 本机 `taobao-picker\server\v3\wxshop.py` 只有 `list_categories()`（读已开通）与商品接口，`grep category.*apply|类目.*申请|资质.*提交|保证金` 在 `微信小店自建上货台\` 零命中、在 `taobao-picker\` 无申请类封装 —— 现有代码没封装申请接口，但**官方开放接口存在**。
- 微信开放文档 [类目管理](https://developers.weixin.qq.com/doc/store/shop/guide/catalog/category.html) 明确：`POST /channels/ec/category/add`（申请类目 / addcategory，返回 `audit_id`）、`GET /shop/ec/category/all`（全类目树含资质）、`POST /shop/ec/category/detail`（含 `attr.deposit` 保证金）、`POST /shop/ec/category/getbizcatflowlist`（审核单）、`POST /shop/ec/category/get_category_relation_list`（权限）。
- 本机 `微信小店自建上货台\wxapi.py` 已封装 `categories()` / `category_detail()`，可直接复用凭据与 token 逻辑；两店 AppID/AppSecret 在 `shops.json`，逐店 `stable_token` 取 token，不串号、不用扫码、不碰主人标签页。
- 官方文档「申请类目」入参按 [api_addcategory.md](https://developers.weixin.qq.com/doc/store/shop/API/channels-shop-category/api_addcategory.md)：`category_info.cats_v2`（根→叶 cat_id 数组）+ `is_new_apply_cat=true` + `license_group_list`。本轮家具类目 `qua`/`product_qua` 均为空 → 传空证照组，实测 100 次 `errcode=0` 直接免审通过。
- 证据文件：`D:\DSH_Cache\cache\tmp\ego\` 下 `probe_A.json` / `probe_B.json` / `submit_log.jsonl` / `submit_result.json`（每条含请求体与平台返回原文）。

## 2. 全店保证金账户当前余额（两店分别）

`POST /channels/ec/funds/getbalance` 真读：

| 店 | available_amount | pending_amount | 原始返回 |
|:--|--:|--:|:--|
| A 欢轴家居 | 0 | 15000 | `{"errcode": 0, "errmsg": "ok", "available_amount": 0, "pending_amount": 15000, "sub_mchid": ""}` |
| B 崇耿 | 0 | 0 | `{"errcode": 0, "errmsg": "ok", "available_amount": 0, "pending_amount": 0, "sub_mchid": ""}` |

**口径说明（决定「会不会补缴」）**：`getbalance` 返回的是**结算资金账户**（可提现/待结算），**不是保证金专户余额**；试过的 3 个保证金专户探测路径全部 `40066 invalid url`，本机无该 API。按 vault 规则原文（`wechat-shop-research\rules\-_20221102__2022_11_02.md` 行 37）：「当申请新的商品类目后，若应缴类目保证金金额高于当前的保证金余额，则商家须补足差额后才能发布新申请类目的商品」；**多类目取金额最高者、不叠加；加了类目未发品不计入**。因此本轮用「已开通类目中的最高应缴」作为不触发补缴的判据：

- A 店已开通 1562 条，逐条 `category/detail` 读 `attr.deposit`：最高 **5000 元**（`7119 军迷装备` / `7118 军迷用品` 5000 元），其余 2000 元×780、1000 元×780。
- B 店已开通 46 条：最高 **2000 元**（沙发系列 `549146`–`549153` 等 22 条 2000 元，另 24 条 1000 元）。
- 结论：任何 **≤2000 元**的新家具类目，两店新增后全店应缴都不抬高 → 满足「不让我继续再补交保证金」。B 店专户实际余额未知，但按「未发品不计入 + 取最高不叠加」口径不触发补缴；**若平台对 B 店另判需补缴，本轮零支付、也未点任何缴纳按钮**，会在后台提示，交由主人处理。

```
POST /cgi-bin/openapi/quota/get {"cgi_path":"/channels/ec/category/add"}
→ {"errcode":0,"quota":{"daily_limit":100,"used":108,"remain":0},
   "rate_limit":{"call_count":1050000,"refresh_second":60}}

  "errmsg":"reach max api daily quota limit rid: 6af00b83-0648efee-120143c4"}
```
