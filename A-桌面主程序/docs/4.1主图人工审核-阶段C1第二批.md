## 二、三个真 bug（都不是"感觉"，是复现出来的）

### bug 1 · `ValueError: Invalid format string`（保存新版本必失败）

```
F:\pyenvs\douyin\Scripts\python.exe  →  Python 3.13.15
  time.strftime("%H%M%S%f")             →  ValueError: Invalid format string   ← 复现
  datetime.datetime.now().strftime(...) →  正常
```
`tab_wall_main.py:160` 给临时文件起名时用了 `%f` —— **`%f` 是 `datetime` 专有指令，Windows 的
`time.strftime`（MSVCRT）不支持**，所以 `save_version()` 第一行就抛，走不到存图。

修法：`time.time_ns()`，并把 `cv2.imwrite` 换成 `imencode`+写字节（`cv2.imwrite` 在中文路径上会静默失败）。

### bug 2 · 选区错位/平移（真凶：把宽高当成了右下角）

```python
# 旧
maskgen.draw_rect(self.mask, (x0, y0, x1 - x0, y1 - y0), 255)
# maskgen.draw_rect 的第 2 个参数是 (x1, y1, x2, y2) **含端点**
```
于是遮罩真正落在 `(x0,y0)-(宽,高)` 这个不相干的位置；`x0 > 宽` 时排序后变成 `[宽, x0]` ——
**看上去就是"整体平移 + 变形"**。

另外两处一起修：
- 橡皮筋显示 `abs(pt.x() - x0)`（x0 已是较小值）⇒ 往左/上拖恒为 0，被压成一条线；
- 起手/松手用不同取整（`to_image` 截断 vs `to_image_clamped` 四舍），边界差 1px。

修法：`draw_rect(..., (x0, y0, x1, y1))`；橡皮筋用相对起点的位移；起手与松手都用 `to_image_clamped`（出界夹到图内，矩形允许从留白处起手）。

### bug 3 · `_load()` 里调 `_build()`

点「恢复上一版」会把整套控件**再建一遍**。改成「构建一次 + 可重复 `load()`」，并把 `load` 与 `_build` 分开。

### 另外两处按你的要求改了

- **左图紫色填充 / 右图只画红线**：`Canvas.mask_style`（`fill` / `line`）。右图用 `erode` 取轮廓，
  **实测 选区正中 alpha=0**（修补效果不被遮住）、边框仍有 436 px 可见。
- **隐藏不稳的工具**：`ENABLE_EXTRA_TOOLS = False`，画笔/橡皮/套索/图章按钮**不创建**（实现代码一行没删，
  开关改回 `True` 就回来）。只用矩形 + TELEA/NS + 撤销/重做。
- **没改图也能确认**：新增「✓ 原图合格」→ `api.confirm_original()`（只写台账，不生成版本、不动主图指针）。
  `confirm_ok()` 在"结果==原图"时也会自动走这条路，不再强迫先存版本。
- **详情图入口只预留**：`查看该商品详情图` 弹说明"请在 4 打码处理"，不做跳转、不重复检测。
