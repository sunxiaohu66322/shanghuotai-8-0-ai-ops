### D-33 二级域名不可用（缺 DNS 记录，非代码问题）
- **现象**：`shanghuotai.1319766413.lifestyle` 无 A/AAAA 记录；`abc-test-xyz.1319766413.lifestyle` 同样无 → 该域名**没有通配符记录**。
- **实测**：`nav.1319766413.lifestyle` → 104.21.41.229 / 172.67.195.152（可用）；其余子域解析为空。
- **凭据**：本机无 `CF_*` 环境变量，`~/.cloudflared/cert.pem` 不存在 → 无法用 `cloudflared tunnel route dns` 自动添加。
- **当前替代**：路径式隔离 `/p/shanghuotai` + `/api/public/projects/p-007c76a0/*`，已满足「每项目独立位置、互不混淆」。
- **补齐方式（二选一）**：① Cloudflare 面板 → 该域 → DNS → 添加 CNAME `shanghuotai` → `2248bcf3.cfargotunnel.com`（Proxied），再在 Zero Trust → Tunnels → 2248bcf3 → Public Hostnames 加 `shanghuotai.1319766413.lifestyle → http://127.0.0.1:9180`；② 提供 `CF_API_TOKEN`（Zone:DNS:Edit 权限）由脚本自动建。

### D-34 项目页不列资料（可用但有摩擦）

## 第 7 轮新增（2026-10-25 11:50）

### D-35 类目全空缺 —— 导出「商品分类」列必空（阻塞级）
- 事实：12 件商品 `v3_product.category_path` **全部为空**（源卡只给 `_extra.catId`，没有中文类目路径）。
- 影响：微信 19 列与抖店 16 列的「商品分类」都只能是空，且导出时会 warn「分类空缺」。抖店示例是 `服装 > 内衣裤袜 > 居家服/睡衣`，**后台大概率不接受空分类**。
- 现状：`doudian._category()` 已按"缺就留空 + warn"处理，**没有编造任何类目**。
- 需做：4.2 类目映射界面（来源类目 → 微信目标类目 / 抖店目标类目，人工选），或在导入时补 `category_path`。
