## 2. 数据库变更（只有新增，没有改旧表）

```sql
CREATE TABLE IF NOT EXISTS v3_image_edit (
    edit_id, image_id, product_id, version_image_id, pack_code,
    mask_path, mask_sha256, regions_json,
    method, radius, expand_px, inspect_json, quality,
    status,           -- draft | saved | confirmed | failed
    note, actor, created_at, confirmed_at
);
+ ix_v3_edit_image / ix_v3_edit_ver / ix_v3_edit_pid
```

**版本本体不在这张表里** —— 仍写 `v3_image`（`status='candidate'` → `approved`，`parent_image_id` 指向被编辑的那张）。
本表只回答「这张新图是怎么补出来的、谁看过了」。

**回滚**：`DROP TABLE v3_image_edit;` —— 三个索引随之消失，`v3_image` / `v3_product` 一个字节不动。

> **如实交代**：应用启动时 `store.init()` 会 `executescript(SCHEMA_SQL)`，所以这张表是
> **02:26 由界面冒烟时的正常启动建出来的**，不是我手工执行 DDL。
> 实测结果：`v3_image_edit` 0 行、`v3_audit` 仍是 1301 条（最新 23:21，早于本次），
> `v3_product` 328 / `v3_image` 1589 —— **业务数据零变化**，只有 DDL 与 `v3_meta.schema_applied_at`。

## 3. 两处口径打架（阶段 A 查出，本轮已修并有断言）

### ① 照片墙不认「已确认的主图」

```
改前：library.local_image(pid) → role='main' order by sequence → 永远第一张
改后：先看 v3_product.main_image_id → 命中就用它 → 失效才退回排序
```
**实测（T21–T23）**：确认前返回 image 5；确认新版本后返回 2104；撤销后回到 6。

### ② 存版本会抹掉第三步精筛结论

```
改前：images.import_new() 里无条件 store.set_product_status(pid, 'image_handoff')
改后：import_new(keep_status=True) 不碰状态；默认 False 保持旧行为
```
**实测（T7–T9）**：非 blocked 商品 `fine_screened` → `keep_status=True` 后仍是 `fine_screened`；
同一件用默认参数再导一次 → `image_handoff`（证明开关不是空转）。

> 注：`blocked` 是 `store.set_product_status` 的**受保护状态**，任何写入都改不动它 ——
> 所以初版测试拿 blocked 商品验证这个开关是**测不出来的**，已改成挑非 blocked 商品。

## 4. 接口（阶段 D/E 直接接，不再重设计）

```python
# server/v3/edits.py（唯一写入方）
ensure_table(conn)                                    # 幂等
save_draft(conn, pid, base_image_id, mask, regions, method, radius, expand_px) -> {edit_id, mask_path}
save_version(conn, pid, base_image_id, result_path, mask, regions, method, radius,
             expand_px, inspect_result, actor, keep_status=True) -> {version_image_id, edit_id, parent_image_id}
confirm(conn, pid, version_image_id) -> images.approve() 的结果（只移指针）
confirm_original(conn, pid, base_image_id, note)      # 「原图即合格」，不动指针
state_of(conn, image_id) -> {has_draft, has_version, confirmed, last_method, last_quality}
summary_map(conn, image_ids) -> {image_id: state}      # 照片墙批量用
list_edits / latest / mark_failed

# app/v3img.py（只读）
MainLib(db, root).packs() / mains(pack, q, state) / image(iid) / versions(iid) / ocr_boxes(iid) / stats()

# app/ui/tab_wall_main.py（UI→写层的适配）
WallMainApi.save_draft / save_version / confirm / confirm_original / state / ocr_boxes
```

**写库安全三条**：① 只有按钮触发才开写连接，用完即关（不长期持写锁）；
② 第一次写之前 `backup_once()` 复制 `v3.db`；③ 失败原样返回，界面不写"已完成"。
