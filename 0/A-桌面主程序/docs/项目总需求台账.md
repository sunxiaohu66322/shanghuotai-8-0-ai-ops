## 〇、项目边界（2026-10-25 重置，唯一口径）

**本项目 = 上货台**：详细商品卡导入 → 商品管理 → 精筛 → 图片/视频处理 → **微信/微店与抖音**平台上货数据包导出。

**不在本项目内**（已移出，见 `docs\归档-非本项目-EGO三项.md`）：
Ego / Ego TaskSpace · 抖音收藏夹同步 · 收藏夹数字 2516 · `/api/douyin/logs` · STT/转写/视频理解 · 其他项目的 Dashboard API。

**唯一成功标准**：用户能从**真实详细商品卡**出发，得到**经过筛选、修改、审核、并且能真的导入目标平台**的完整商品包。
页面能开 ≠ 成功；能出 CSV ≠ 成功；测试函数 PASS ≠ 成功。

## 一、状态定义

`未开始` · `进行中` · `待验证`（代码已改、未实跑） · `已验收`（有真实运行证据并满足验收标准） · `阻塞`（有明确外部依赖）
