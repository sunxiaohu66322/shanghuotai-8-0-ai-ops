### 3.3 上下架（本轮补做，原来是 0 条记录）

`do_status` 原实现**拿接口返回当成功**，实测撞到任务书§一点名的假成功：`listing` 返回 `errcode=0`，但读回 `status` 仍是 0，且商品进「审核中」后 `delisting / update / delete` **全部报 `10020047 商品正在审核中`**，等于把商品锁死。

修法（已实测闭环）：提交后 sleep 1.5s **重新读商品状态**再下结论；下架遇到审核中自动走新加的 `POST /channels/ec/product/audit/cancel`（`wxapi.cancel_audit`）撤回。

```
UP   : True | 上架请求已受理，商品进入审核（读回 status=0，官方审核通过后才变 5）；审核期间无法编辑/删除，如需回退用「撤回审核」
DOWN : False | 商品在审核中已撤回（现在可编辑/删除；未下架）
EDIT : True | 撤回后整对象更新成功 —— 证明已回到可操作态
```

等级：**L3→L4**（受理+读回+状态解释+撤回通路均实测）。要算完整 L5 需等官方审核真正通过后测「已上架→下架→读回 status≠5」，本轮未等到审核结果，标 **未验证**。
