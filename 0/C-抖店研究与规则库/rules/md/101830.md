# 第一章 概述
## 1.1 目的及依据
为明确平台内商家保证金的缴纳、调整、补缴、赔付及退回等事宜，促进商家更好地服务消费者，根据《中华人民共和国电子商务法》《中华人民共和国消费者权益保护法》等法律法规，以及平台《电子商务开放平台店铺服务协议》、《商家违规行为管理总则》、《售后争议处理总则》等相关协议及规则，制定本规范。
## 1.2 适用范围
本规范适用于平台内所有商家（全球购、即时零售商家除外）。
# 第二章 实施细则
## 2.1 保证金的定义
保证金，是指商家向平台缴纳，用以保证平台协议和规则的履行以及担保商品和服务质量的款项，包括基础保证金和体验保证金。商家需同时关注基础保证金和体验保证金的应缴纳金额（简称应缴额）和余额。未及时补足可能影响提现、商品发布或交易等店铺功能。
基础保证金：商家向平台缴纳的开店押金，用于保证商家在店铺经营期间遵守平台协议和规则，合规经营。
体验保证金：商家向平台缴纳的保障资金，主要用于订单退赔等售后保障。

## 2.3 保证金应缴额调整
2.3.1 基础保证金：平台将根据商家上个自然月商品交易总额（GMV）调整基础保证金应缴额。
平台每月1号会向额度提升的商家发送通知，每月8号更新基础保证金应缴额。
2.3.2 体验保证金：若商家近30天无特殊类目订单成交，且最后一笔特殊类目的订单签收满n天，且无未完结的售后订单，平台将降低体验保证金应缴额。n天为商家自行设置的售后服务有效期与平台要求的售后服务有效期中的较高值，最低不少于30天。平台售后服务有效期详见《【商家售后服务有效期限】实施细则》。
2.3.3 商家在经营期间发生违规行为、被第三方投诉举报或索赔，或其关联店铺存在违规情形的，平台将结合违规类型、影响范围、待处理订单或投诉金额等因素综合判断，并通过站内信或【抖店后台-资金-保证金】页面通知商家调整结果及补缴要求。
## 2.4 保证金划扣及赔付
2.4.1 若商家在经营期间违反平台协议或规则，发生重大负面舆情，或被第三方投诉、举报、索赔、诉讼、仲裁等，平台有权按平台协议或规则冻结、扣划保证金，用于赔付消费者、赔偿平台损失或支付商家应承担的其他费用。
2.4.2 当商家的保证金不足以赔付消费者、平台及其他权利人损失时，商家应自行承担额外的赔付金额。
## 2.5 保证金的补缴
当商家保证金余额低于应缴额时，平台有权从商家货款账户划扣相应金额至保证金账户。若商家货款不足，平台将通知商家补缴，并根据欠款情况采取相应处置措施（见下表）。商家将保证金补足至应缴额后，平台将实时撤销相应处置，恢复相应店铺功能。

## 2.6 保证金退回
注：本部分提及的 “售后预留金”，是平台为保障消费者售后退赔从商家货款中冻结的资金。规则参考：《售后预留金实施细则》
2.6.1 退回方式：
（1）店铺经营中部分退回：
【条件】保证金余额大于应缴额的部分可提现；如售后预留金未足额冻结，体验保证金中对应未冻结金额的部分不可提现。基础保证金和体验保证金每周各可提现一次；因保证金扣除等原因导致实际可退金额小于申请提现金额时，提现将失败。
【流程】商家须在【抖店后台-资金-保证金账户-可提现金额】点击【提现】提出申请，平台将在申请发起后的1-3个工作日将保证金退回至商家填写的账户中。如遇集中批量退款等特殊情况到账时间可能延长，以实际到账时间为准。
【方式】个体工商户商家可选择退还至经营者个人银行卡或营业执照对公银行账户；企业商家退还至企业对公银行账户。
（2）店铺关闭余额退回：
【条件】商家可在店铺关闭后，申请退还剩余保证金。
【流程】商家须在【抖店后台-店铺-申请关店-申请提现/退回】页面提出申请，平台将予以审核（包括但不限于申请的材料齐全、信息完整无误、签字盖章完整、无未结算完的结算单等），审核通过后，平台将在1-3个工作日内将保证金退回至商家填写的账户中。如遇集中批量退款等特殊情况到账时间可能延长，以实际到账时间为准。
【方式】退回方式同2.6.1（1）
2.6.2 因保证金可能用于售后退赔等用途，平台开具的保证金收据不作为退回依据。实际退回金额以【抖店后台-资金-保证金账户】页面展示的余额为准。
## 2.7 保证金合法性要求
商家应保证其用于缴纳保证金的资金来源合法，且商家对其依法享有处分权；若商家保证金系由第三方代为支付的，商家应保证该第三方清楚知晓所支付款项的性质、用途等情况且同意代为支付，并保证平台不会受到任何第三方就商家保证金主张其享有任何权利或以任何理由要求返还。
## 2.8 其他
2.8.1 保证金的缴纳、赔付、退回等过程中所产生的银行费用等第三方费用，由商家承担，平台可从保证金余额中扣除。
2.8.2 若商家信息变更，需根据变更情况的不同（如单纯账号变更、公司更名、公司注销等），按照平台要求准备相关材料文件，并提前30个自然日通过【抖店后台-店铺-店铺管理-店铺信息管理】页面操作更新，否则因商家信息的变更而造成的支付失败、延迟、错误，损失将由商家自行承担。
