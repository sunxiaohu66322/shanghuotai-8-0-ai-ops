# 一、平台导向
为保障消费者人身财产安全、知情权与公平交易权，防范违法违规、安全隐患、履约风险等问题，维护平台健康经营生态与公平竞争秩序，平台特制定本规则，明确法规禁止类商品/信息的禁售范围、违规处置、整改与申诉流程。本规则依据《中华人民共和国电子商务法》、《中华人民共和国消费者权益保护法》、《网络交易监督管理办法》等相关法律法规及监管要求制定，具体违规依据详见本规则"常见违规类型"中的"规则背景及依据"部分。
# 二、违规定义
发布法规禁止商品/信息，指商家与创作者通过平台发布、售卖、宣传或推广法律法规明确禁售/禁止分享的商品或信息。同时，下列规避平台管控的行为也属于违规，包括但不限于：以涂抹、谐音、生僻字等方式规避识别，或在商品发布未通过后隐藏、替换重要信息重新发布等。
平台识别违规行为的来源包括但不限于：商品信息（如商品标题、商品描述、商品图片等）；店铺信息（如店铺装修、店铺名称、店铺分类、店铺公告、店铺logo等）；交互信息（如平台社区、飞鸽等平台发布的信息）；直播间信息（画面展示、口播、评论信息等）；短视频信息（视频画面、讲解、评论信息等）；其他推广展示信息，如橱窗信息、商品卖点、创作者签名、创作者个人主页信息等。

# 五、整改建议及申诉
## （1）整改建议
立即下架或删除所有禁售商品及相关信息，停止宣传与销售行为。
核对商品类目，确保仅发布平台已开放类目下的合规商品。
清理违规素材、标题、关键词，不得以涂抹信息、生僻字、谐音词等方式规避平台审核。
关联主体同步整改，不得通过多账号、多店铺等方式转移或规避违规行为。
请注意，因发布法规禁止商品/信息产生的单据，完成整改后也不予撤销，请商家知悉并及时持续规范经营行为。
