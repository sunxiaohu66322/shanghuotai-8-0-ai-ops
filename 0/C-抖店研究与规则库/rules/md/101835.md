# 七天无理由退货服务规范
## 第一章 概述
### 1.1 目的及依据
为保障消费者权益，依据《中华人民共和国消费者权益保护法》、《网络购买商品七日无理由退货暂行办法》等相关法律法规及平台协议制定本规范。
### 1.2 适用范围
本规则适用于小店平台内的所有商家和消费者。
### 1.3 服务标识
支持“7天无理由退货”的商品，会在商品详情页的服务保障栏展示标识（如“7天无理由退货”标签），具体情况以页面展示的为准。
## 第二章 基础要求
### 2.1 退货时效
消费者需在收到商品之日起七天内，对支持“7天无理由退货”且符合完好标准的商品发起退货申请（一般为物流显示签收商品的次日零时起168小时，即7天内）
### 2.2 赠品处理
消费者退货时需将商品、配件及赠品（实物、积分、代金券等）一并退回。若赠品无法退回或已损毁，商家可按赠品价值扣除相应价款，但不得因此拒绝商品退货。发票遗失不影响商品退货，若发票遗失，消费者应承担相应税款。
### 2.3 商品完好标准
消费者退回商品需保持完好，具体标准如下：
2.3.1 通用标准
商品本体、配件及商标标识完整无缺，不存在受损、受污、刮开防伪涂层、激活（授权）等情况；无难以恢复原状的外观类使用痕迹以及不合理的个人使用数据留存等数据类使用痕迹。
因查验需要打开包装或进行合理调试（如确认功能），不影响物品完好性；若超出查验和确认商品品质、功能的需要而使用商品，致使商品价值出现较大幅度贬损的，应认定商品不完好；若商家对商品功能完好有特殊要求，建议商家明确指出因使用、激活、损耗后造成商品不完好的具体阶段或场景。
特殊包装（如具备防伪性、唯一性的包装）的商品，商家应当在事前对其保护要求进行显著提示（例如在商品详情页、包裹内进行醒目提醒）。针对合理的包装保护要求，消费者应谨慎保护，若因包装损坏导致商品价值贬损或功能丧失，可认定商品不完好；若未进行显著提示或包装不具备特殊性，则按照一般包装标准处理。
2.3.2 一般商品包装的完好标准
商品原包装未缺失且整体结构完整；在包装、运输或拆卸过程中出现的适度变形、污渍、局部破损等难以避免的形态变化，不认定为影响商品包装的完整性。

| --- | --- |

| 运动户外 | 1.健身训练/骑行类商品未安装/未使用/未激活； 2.户外仪表未进行实名认证且未联网激活； 3.冲浪潜水类商品未实际使用; |

| 母婴类 | 尿裤湿巾类商品外包装未拆封； |

| 食品饮料/宠物食品及用品 | 若有一次性密封外包装需未拆封； |
| 玩具/乐器类 | 1.若有胶条/塑封，需保持未拆封状态； 2.若有商标标识、防伪/防盗/防损扣/标/贴（不影响合理试用），需保持完好未拆； |
| 汽车/自行车零配件 | 1.汽车/摩托车/电动车零配件无使用/安装痕迹，电池/电瓶未通电； 2.汽车耗材类必要的一次性密封包装未被拆封； |
| 箱包皮具 | 1.无显著使用痕迹/磨损/划痕； 2.若有商标标识、防伪/防盗/防损扣/标/贴（不影响合理试用），需保持完好未拆； |
| 家居用品 | 1.家居类和家纺类商品商标标识未被摘除或裁剪，商品无污损现象，封签未被拆封、移位、撕毁等；床垫表面保护薄膜需未破损。 2.净化除味/一次性毛巾/浴巾类一次性密封外包装未破损（无包装则不适用7天无理由退货），或香薰蜡烛无使用痕迹； |
| 家具家装 | 1.桌/床/柜/架/椅等组装类家具尚未安装；床垫表面保护薄膜未破损且无使用痕迹；马桶/浴室柜/智能/电子门锁/灯饰等家装类未安装； 2.地板/瓷砖/壁纸无使用痕迹； 3.涂料漆类若有一次性密封外包装需未拆封； 4.定制类主材不支持7天无理由退货； |
| 电子仪器类 | 1.电子电器类无以下任一情形：未经授权维修/改动，破坏/涂改强制性产品认证标志、指示标贴、机器序列号等；存在难以恢复原状的外观使用痕迹，或产生激活/授权信息、个人数据留存等数据类痕迹； 2.电子元器件商品未焊接操作，集成电路未安装在IC底座，易耗品（导热硅脂/导热膏、电子胶/灌封胶/密封剂/粘合剂、导电胶、导电墨水）一次性密封包装未拆封； |
| 打火机类 | 1. 棉芯（若有）未注油使用 2. 打火轮/火石无明显磨损 |
| 二手奢侈品 | 1.防伪签/防盗扣/原膜（如腕表保护膜）完好； 2.无新增穿戴/使用/洗涤/污损/划痕/磨损痕迹； |
注：密封，指商品外包装被生产厂商加以了封条（签）或整体塑（密）封的包装措施。
## 第三章 服务分类与标识
### 3.1 适用范围分类：
| 是否适用“7天无理由退货” | 商品类型 | 举例说明 |
| --- | --- | --- |
| 不适用7天无理由退货 | 定制类商品 | 个性定制、设计服务等 |
|  | 鲜活易腐类商品 | 鲜花绿植、水产肉类、新鲜蔬果、活体类等 |
|  | 在线下载或者客户拆封的音像制品、计算机软件等数字化商品 | 充值点卡、加油卡等 |
|  | 交付的报纸、期刊 | 期刊杂志等 |
|  | 服务类 | 本地服务类、教育培训、装修设计/施工/监理等 |
|  | 人体用药 | / |
| 商家可选支持“7天无理由退货” | 拆封后影响人身安全或者生命健康的商品，或者拆封后易导致商品品质发生改变的商品 | 食品、酒水、内裤、塑身裤、塑身连体衣、乳贴、插片/胸垫等贴身用品等 |
|  | 一经激活或者试用后价值贬损较大的商品；或非生活消费所需的商品 | 智能设备（如VR头盔等）、商用厨具、工业品、办公耗材、电动车整车、黄金、铂金、K金、投资贵金属等 |
|  | 其他根据商品性质并在消费者购买时确认不宜退货的商品 | 临近保质期/有瑕疵的商品等 |
| 适用7天无理由退货 | 除上述类型外的其他商品 | 服装鞋靴(除贴身用品)、家居日用、家纺类、厨房/烹饪用具、家电等。 |
### 3.2 服务分类
3.2.1 具体分类
| “7天无理由退货”分类 | 说明 | 商品举例 |
| --- | --- | --- |
| 支持7天无理由退货 | 商品支持签收后的7天内在商品完好的情况下由于消费者主观原因申请退货 | 如服饰、鞋靴、童装童鞋类等商品 |
| 7天无理由退货（一次性包装未破损） | 商品支持签收后7天内由于消费者主观原因申请退货，但商品外包装已拆封、缺少附件、外观损坏等任一商品不完好情形，均不适用7天无理由退货 | 如个护清洁、食品、美妆等商品 |
| 7天无理由退货（安装后不支持） | 商品支持签收后7天内由于消费者主观原因申请退货，但商品已安装、缺少附件、外观损坏等任一商品不完好情形，均不适用7天无理由退货 | 如健身车、踏步机、挂装空调等商品 |
| 7天无理由退货（激活后不支持） | 商品支持签收后7天内由于消费者主观原因申请退货，但商品已激活、缺少附件、外观损坏等任一商品不完好情形，均不适用7天无理由退货 | 如笔记本、台式机、手机等商品 |
| 7天无理由退货（使用后不支持） | 商品支持签收后7天内由于消费者主观原因申请退货，但商品已使用、缺少附件、外观损坏等任一商品不完好情形，均不适用7天无理由退货 | 如冲浪服、刻录碟片、香薰蜡烛等商品 |
| 7天无理由退货（定制类不支持） | 商品支持签收后7天内由于消费者主观原因申请退货，但定制类商品不适用7天无理由退货 | 如定制家居、定制服装等商品 |
| 7天无理由退货（合约版不支持） | 商品支持签收后7天内由于消费者主观原因申请退货，但合约版商品不适用7天无理由退货 | 如合约版（联通、电信、移动）手机 |
| 7天无理由退货（防伪签、密封条、原膜损毁不支持） | 商品支持签收后7天内由于消费者主观原因申请退货，但商品封签、防伪签、密封条、商品原膜（如腕表在出厂时起保护作用贴在腕表表面的一层保护膜）损毁、缺少配件、外观新增磨损等任一商品不完好情形均不适用7天无理由退货。 | 如二手3C数码、二手奢侈品等 |
3.2.2 服务规范
商家应根据商品真实属性及合理附加条件，正确选择对应的服务标签，不得任意扩大不适用/有条件适用“七天无理由退货”的商品范围。例如，商家不得为非定制商品选择并要求适用“7天无理由退货（定制类不支持）”标签。
拆封/激活/安装/使用后不支持七天无理由退货的商品、临期商品、瑕疵商品及其他根据商品性质可以不支持七天无理由退货的商品，商家未选择正确服务标签的，则商品已拆封/已激活等情况不能作为影响商品完好的依据，商家也不得以商品详情页、直播间等渠道已告知为由拒绝履行七天无理由退货义务。
平台要求支持七天无理由退货的商品，商家单方或买卖双方约定不支持七天无理由退货的行为无效，但平台以普通人认知判断消费者为非生活消费所需购买的情形除外。
商家存在违反前述七天无理由退货服务规范情形的，平台有权通知商家限期整改；商家逾期未整改或整改不符合要求的，平台有权对相关商品采取下架等处置措施。
## 第四章 附则
平台有权依据运营情况对规则进行调整，并以公告形式予以公示；
商家应严格遵守国家法律法规以及与平台所签订的协议，依法依规承担相应法律责任和接受平台处置。
