# 一、商家客服消极服务
### （一）常见情形
商家在服务过程中存在指责嘲讽贬低消费者行为（包括但不限于人身贬低、质疑动机、阴阳反讽、指责抱怨等），且该行为未达到辱骂、威胁、骚扰的严重程度；
商家单日或自然周存在大量不响应（无人工客服应答）、响应慢的行为；
商家无正当理由（用户发送辱骂信息除外）在飞鸽im上拉黑消费者，影响消费者正常的店铺咨询、售后服务保障；
对于消费者已购买商品发起的服务咨询，商家单日或自然周存在未与消费者积极沟通处理的消极应对行为，导致消费者对商家服务不满意。这些消极应对行为包括但不限于：
在工作时间（8点~23点）内，商家未安排可处理售后问题的客服，要求消费者择期咨询；
在单通会话中，商家人工客服让消费者等待（如：等一下、稍等、我看下等），但后续无商家回复；
商家强硬拒绝消费者的服务诉求，且未提供合理的原因或凭证的；
商家人工客服出现大量回复与消费者服务诉求无关的内容，或大量机械重复的回答；
商家无效处理、不处理服务工单，或消费者投诉监管后商家24小时内仍不响应/未有效响应服务工单；
商家存在其他违反《飞鸽服务使用管理规范的行为。
### （二）违规处置
#### 针对商家客服存在指责嘲讽贬低消费者等行为，平台将视违规程度对商家进行相应处置，具体如下：
自然周内出现3通以上会话存在违规，处以警告公示；
自然周内出现10通以上会话存在违规，扣除违约金100元；
自然周内出现15通以上会话存在违规，扣除违约金200元。
商家嘲讽贬低、无理拉黑消费者的，平台有权根据具体情形，从商家账户中扣除订单实际支付金额的5%用于赔付消费者，单次赔付最低不少于5元，最高30元；用户滥用上述规则发起赔付申请，平台有权不支持赔付。
2. 商家未及时处理“平台介入工单”，违规处置：
每个自然周内：
| 违规程度 | 处置措施 |
| --- | --- |
| 【工单量≥5 且 30%≤逾期率＜60%】或【工单量＜5 且 逾期量=2】 | 警告 |
| 【工单量≥5 且逾期率≥60%】或【工单量＜5 且 逾期量≥3】 | 一次性扣除自然周成交金额×0.15%的违约金（最低30元，最高不超过200元） |
指标说明：
自然周：指每周周一00:00:00至周日23:59:59。
工单量：指自然周内商家应当处理的平台介入工单总量。
逾期量：指未在平台规定时效内响应的服务工单数量。
逾期率：指逾期量除以服务工单量所得比例。
违约金计算基数：以对应自然周内商家成交金额为计算基数，具体以平台系统计算结果为准。
3. 商家客服存在消极服务行为，平台还有权要求店铺进行考试、开通智能客服接待等。若商家消极服务严重影响消费者体验，导致产生舆情、监管投诉且商家仍不配合处理的，平台有权根据商家响应情况采取公示警告、限制发品7天等处置措施。
# 二、商家无故拒绝售后
### 商家无故拒绝售后具体指什么？
商家消极处理消费者售后申请，无理由关闭售后申请，或消费者因商家原因无法完成售后申请，且经平台介入判定为商家责任。
### 常见违规情形
商家以要求消费者修改售后原因为由拒绝消费者售后，且修改后的售后原因非消费者真实原因；
商家以下列原因拒绝消费者售后，但未上传与消费者有效的沟通记录，包括但不限于：买家误操作/取消申请、买家已签收、问题已解决、已与买家协商一致、未收到货/退货单号有误、要求修改退款金额、退回地址不符等；
备货中用户申请退款，商家以“已发货”为由拒绝退款，但物流实际揽收时间晚于用户申请售后时间；
当前售后申请错误或需修改售后选项，商家未引导用户主动修改或撤销且拒绝用户申请，未上传有效的沟通记录；
存在物流场景纠纷，商家以商品已签收为由拒绝消费者售后，未主动联系用户协商并引导修改或撤销售后并上传有效的沟通记录；
商家以商品已签收、不支持7天无理由为由拒绝用户申请品质原因退货；
商家以“售后处理时效有限”、“仓库搬迁/放假无人收货”等原因拒绝售后请求；
不支持退货类目消费者发起退款，商家拒绝消费者退款诉求且未提供其他可行售后方案；
因商家拒绝消费者的退款请求，导致消费者发起纠纷，最终平台判商家责任。
### 商家存在无故拒绝售后平台会如何处置？
| 违规程度 | 违规处置 |
| --- | --- |
| 商家售后拒绝率大于行业均值5倍，同时商家日均无故拒绝量达到5笔；且自然周内首次违规的 | 处警告公示，要求商家限期整改 |
| 商家售后拒绝率大于行业均值5倍，同时商家日均无故拒绝量达到5笔；且自然周内违规次数>=2 | 扣除商家违约金100元 冻结近15天货款并停止结算（满足违规单页解除条件后解除） |
| 商家售后拒绝率大于行业均值5倍，同时商家日均无故拒绝量达到10笔；或自然周情节一般>2次；或单个商品售后拒绝率大于行业均值5倍，且日均不合理/无故拒绝量达到5笔 | 扣除违约金300元 冻结近30天货款并停止结算（满足违规单页解除条件后解除） |
其中“结算货款=成交金额剔除退款”，实际统计周期因数据更新可能延迟，以实际显示为准。
此外，若商家存在无故拒绝售后问题，平台有权根据商家服务情形，从商家保证金或货款账户中扣除订单实际支付金额的10%用于赔付消费者，单次赔付最低不少于5元，最高50元；用户滥用上述规则发起赔付申请的，平台不支持赔付。
# 三、商家该如何申诉？
商家收到违规通知时，若不认可该违规处置，可在收到违规通知的7个自然日内发起违规申诉，未在申诉时效内进行申诉处理的，视为商家认可违规处置，具体要求可查看《商家申诉管理规则》。
申诉路径为【店铺-店铺保障-申诉中心】。平台将在收到申诉申请的5个工作日内给予商家申诉结果。
注：商家发起申诉并不影响平台已经做出违规处置决定的效力和执行、公示。仅在平台对商家发起的违规申诉作出申诉成功的认定后，平台会撤回相关处置决定。
