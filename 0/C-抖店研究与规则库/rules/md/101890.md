# 一、违规定义
出售/分享假冒或盗版商品：指商家或创作者出售/分享假冒或盗版商品的行为。
假冒商品：指假冒注册商标商品，即未经注册商标权利人许可，在同一种商品上使用相同商标的商品。
盗版商品：指未经著作权人许可复制其作品的图书、电子书、音像作品和软件等。
# 二、常见违规情形
| 违规行为 | 常见违规认定方式 | 情形说明 |
| --- | --- | --- |
| 出售/分享假冒商品 | 鉴定售假 | 平台抽检/消费者投诉/品牌方反馈，经第三方机构或品牌方鉴定为假冒/盗版商品 如商家或创作者销售二手奢侈品品类商品，商品配件被鉴定为假或鉴定结论为不符合品牌工艺特征 |
|  | 商家或创作者承认售假 | 商家或创作者在沟通过程中承认销售假冒商品，且无法提供真实、有效授权资质和采购链路凭证 |
注：【商品配件假】一般为商品配件本身带有品牌logo标识等有较强品牌属性和品牌价值的配件。
另外，平台可以依据行政/司法机关文书，或平台根据数据排查等其他合理依据认定商家或创作者所售商品为假冒或盗版商品。
# 三、违规处置
## 3.1 平台通过非商品实物检测鉴定的方式判定违规
通过平台数据排查、商家或创作者承认、行政/司法机关认定等非商品实物检测鉴定的方式判断商家或创作者涉嫌出售/分享假冒或盗版商品的，平台有权前置干预或者采取相关风险阻断措施，避免持续产生不利影响，包括但不限于商品限单、挂车商品掉车、货款冻结等。
| 违规程度 | 处置措施（商家） | 处置措施（创作者） |
| --- | --- | --- |
| 首次违规，且违规商品数量少，或未造成较大负面影响 | 商品封禁 店铺限制发品14天 冻结违规商品近90天货款的4倍金额并停止结算，时长90天 | / |
| 二次及以上违规 或商家或创作者承认售假，且违规商品较多或造成较大负面影响 或发布违规商品数量多、违规商品销量大造成较大违规影响，或造成大量消费者投诉等 | 店铺清退 冻结货款及停止结算1年 扣除违约金（按违规商品近60天结算金额进行扣除，最低2000元，最高5万元） 注：“冻结货款及停止结算”处置措施，满足冻结周期后，需同时满足违规详情页面所列解冻条件后方可解冻 | 直播中断 视频图文购物车下架、视频自见 永久关闭商品分享功能 冻结佣金账户1年 违规商品成交订单暂停结算1年 |
| 存在关联主体违规 | 店铺清退 | 永久关闭商品分享功能 |
| 注：针对二手奢侈品部分配件被鉴定为假或部分配件被鉴定不符合品牌工艺特征：首次违规的，将对违规商品做封禁，并冻结违规商品近60天货款180天；第二次违规的，除违规商品封禁外，将对店铺停业整顿3天，同时冻结违规商品近90天货款180天；若继续出现违规行为，将按违规场景最高档执行清退、冻结货款等处置 |  |  |
## 3.2 平台通过商品实物鉴定的方式判定违规
平台委托第三方检测或鉴定机构、品牌方对商品进行检测或鉴别，商品检测结果为不合格或鉴别结果为不通过的，平台有权采取升级处置措施。
| 违规程度 | 处置措施（商家） |
| --- | --- |
| 经平台抽检鉴定为假冒/盗版商品或存在异常 | 店铺清退 冻结货款及停止结算1年 扣除违约金（按违规商品近60天结算金额进行扣除，最低3000元，最高5万元） 注：“冻结货款及停止结算”处置措施，满足冻结周期后，需同时满足违规详情页面解冻条件后方可解冻 |
| 存在关联主体违规 | 店铺清退 |
此外，若商家或创作者的违规行为造成较大影响，包括但不限于引发大量消费者投诉、违规商品销量或数量较大、引发舆情或监管投诉，或可能致使平台承担相关责任的，平台有权采取必要处置措施，包括但不限于：限制发品、品牌资质摘牌、关闭类目经营权限、限制成交、冻结货款、冻结保证金账户、限制或关闭商品分享权限。违规情形特别严重的，平台可直接对店铺予以清退，并永久关闭其商品分享功能。
# 四、申诉指引
申诉路径：如对该违规处理有疑义，可以登录抖店/百应后台进行申诉。
商家申诉：抖店后台-店铺-申诉与举报-申诉中心-违规申诉
创作者申诉：百应后台-体验-违规账号管理-申诉
申诉时效：商家或创作者可在收到处置通知后7天内发起申诉。
申诉要求：满足以下情形的，可提供相关申诉凭证发起申诉（具体申诉所需凭证以产品页面提示为准）。
情形1：若未销售假冒品牌商品，可提供证明商品为正品的完整凭证，如商标注册证、授权证明资料、合法进货凭证等发起申诉；
情形2：若未销售盗版书籍或盗版视频，可提供含有ISBN和出版社的书籍照片、发行委托书或合法进货凭证等发起申诉；
情形3：若对机构鉴定结果有异议的，可提供相关申诉凭证在申诉时效内发起申请，若逾期未发起申诉的，即代表认可处理结果，涉及抽检样品将不再保存。
# 五、规则解读
## 5.1 平台如何认定商家或创作者涉嫌出售/分享假冒或盗版商品？
为防范售假、保障消费者合法权益，平台有权不定期对商家发布或创作者分享的商品信息、店铺信息、交易行为等进行随机抽查，并综合消费者投诉、品牌方反馈、第三方鉴定等判断商家或创作者是否涉嫌销售假冒或盗版商品。常见类型包括但不限于：
平台通过数据排查认定涉嫌出售/分享假冒或盗版商品：通过商品信息、店铺信息、交易行为、消费者投诉等方式判断商家或创作者涉嫌出售/分享假冒或盗版商品的。
经平台抽检/品牌方鉴定，鉴定结论为假冒/盗版商品或存在异常：
经品牌方（商标权利人）/其授权的代理人鉴定为假：品牌方/其授权的代理人通过商品鉴定或信息比对鉴定，鉴定为假并出具鉴定报告的；
经第三方机构鉴定商品存在异常：平台委托第三方检测或鉴定机构对商品进行检测或鉴别，商品检测结果为不合格或鉴别结果为不通过的；
经平台鉴别商品存在异常：平台通过对商品与样本商品在当前市场流通的最新批次进行比较，发现其外包装或者内容有较大出入，且不属于官方声明的旧批次包装的；或按照商品品牌官网等公开渠道发布的真假鉴别方法进行鉴别，怀疑样本为假的。
商家或创作者承认销售假冒/盗版商品：
商家沟通过程中承认销售假冒商品的，且无法提供真实、有效授权资质和采购链路凭证的；
创作者宣传或沟通过程中承认销售假冒商品的，且无法提供真实、有效授权资质和采购链路凭证的。
行政/司法机关认定商家或创作者出售/分享假冒或盗版商品：各级人民法院通过判决等司法文书或市场监管、海关等行政机关通过行政文书等认定商家或创作者出售/分享假冒或盗版商品的。
除以上情形外，若有其他合理依据认为商家或创作者所售商品为假冒或盗版商品的，平台亦有权采取相关处置措施。
## 5.2 【商家或创作者承认售假】中“承认”怎么理解？
结合当下沟通语境/具体情境（包含商品信息展示、直播间或短视频画面、口播内容、评论等），以普通人认知进行判断，商家或创作者明确承认或通过暗示等手段表示“非正品”等情形，可认定为商家或创作者“承认”。

一、案例背景 汉堡王自2021年5月以来在抖音平台长期稳定自播，不断优化货品，致力于将美味、高品质、价格合理的汉堡带给每一位用户。但是通过商城数据诊断发现，对比其他相似商家自身搜索曝光流量偏低、店铺页曝光和转化率较低。汉堡王期望提升在抖音商城场景的表现，通过提升曝光和点击转化，进而提升品牌的GMV数据。 二、诊断结论及策略方向 诊断结论： 搜索：短视频、商品卡整体曝光点击率低于相似商家，短视频和商品卡成交率较低。 店铺：店铺整体流量较相似商家低，商品曝光点击率较低。 商城推荐：商城曝光和曝光点击率低于相似商家。 核心策略： 前期阶段优化商城基建，8月底筹备百万宠粉日打造内容场+中心场+营销场的全域狂欢。 三、商城优化动作及效果 通过专项优化，汉堡王抖音商城GMV+6%（VS全店占比+4%） 搜索场景：搜索GMV提升+5%，商品曝光提升+45% 店铺场景：店铺GMV提升+13%，商品曝光提升+5% 商城场景：频道及活动页GMV提升+31%，商品曝光提升+361% 亮点动作1：搜索场景优化 搜索GMV提升+5%，商品曝光提升+45% 商品标题添加品牌词、行业热词及营销词，虚拟卡券标题直接分
