# 第一章 概述
## 1.1 适用范围
报名参与平台组织的营销优惠活动或使用平台营销工具自行开展营销优惠活动的小店平台商家、抖音电商全球购商家、创作者、以及参与各类营销优惠活动的消费者。本规则所涉及的达人亦同创作者。
此规则规定了平台内营销优惠活动的生效和叠加，包含商家营销优惠活动、达人营销优惠活动和平台营销优惠活动。具体优惠叠加规则如有其他具体活动规则或招商规则的，以具体活动规则或招商规则为准，具体活动规则或招商规则没有规定的，以本规则为准。
本规则不适用于抖音支付、抖音月付等第三方举办的营销优惠活动，抖音支付、抖音月付等第三方主办的各类营销优惠活动，以第三方主办方发布的相关规则为准。
## 1.2 效力级别
本规则是对“平台规则体系”的有效补充。商家/达人应遵守国家法律、行政法规、部门规章、与平台签署的各项协议及平台各项规则等规定。对任何涉嫌违反国家法律、行政法规、部门规章等规定的行为，本规则已有规定的，适用于本规则。本规则尚无规定的，平台有权根据相关法律、与平台签订的各项协议及平台规则规定酌情处理。
## 1.3名词解释
营销工具：协助营销主体（商家/达人/平台）达成某个营销目标的辅助工具，营销主体（商家/达人/平台）可以通过营销工具创建营销活动，落地营销策略，实现营销目标。
营销活动：或称“营销优惠活动”是指通过营销工具创建的营销活动，活动时间内符合活动要求的用户，购买活动商品，满足优惠生效条件即可享受满减/立减/满返/赠品等相关优惠。
平台单品级活动：为平台组织的商品优惠表现为活动价的营销活动，通过招商方式由商家自主提报、平台审核通过选定商品。如官方大促、商城活动等
子订单：是指用户购买单个商品的某个SKU 1件商品或多件商品生成的订单，称为子订单。
# 第二章 营销工具的分类
根据营销工具的作用、特征、目标等，对所有营销工具进行了层级归类。根据不同的层级归类可区分为单品级营销工具、店铺级营销工具、跨店级营销工具和其他类营销工具。具体分类说明如下
| 层级 | 定义/说明 |
| --- | --- |
| 单品级 | 针对单个商品的打折、减价、一口价等最终表现形式为优惠价的优惠方式， 优惠类型如： 限时限量购优惠价、大促优惠价、超值购优惠价等。 |
| 店铺级 | 针对全店商品或部分商品的满减、多件优惠等优惠方式， 优惠类型如 ：店铺优惠券（含全店优惠券、商品优惠券、会员券等）、店铺多件优惠、店铺礼金、店铺满返、赠品等。 |
| 跨店级 | 针对平台内全部商品或部分商品的满减、立减等优惠方式， 优惠类型如 ： 达人优惠券、 平台通用优惠券（含平台礼金、平台消费券、大促限时优惠券 等）、限时惊喜加补券 、 官方立减、金卡95折 等。 |
| 其他类 | 除单品级、店铺级、跨店级以外且符合使用条件即可使用的优惠方式， 优惠类型如： 达人购物红包、店铺购物红包、平台购物红包等。 |
# 第三章 营销优惠叠加规则
## (一)递进式满减优惠叠加规则
营销优惠叠加规则称为递进式满减优惠叠加规则，即按营销优惠活动的优先级顺序计算并生效对应的优惠，同时不同营销优惠活动存在不同的使用门槛，符合对应使用门槛方可使用对应的营销优惠。
## (二)优惠生效规则
### 1、单品级
同一个商品的同一个SKU在一个时间段内，仅生效一个单品营销活动，其他招商规则或活动规则有特殊规定的除外。
平台组织的单品级活动优先级高于商家自主设置的单品级活动，平台组织的单品级活动优先级以平台具体的招商规则为准。
### 2、店铺级
订单满足店铺级营销优惠活动的生效条件即可使用对应优惠，具体而言：
（1）单件商品下单时，店铺优惠券、店铺新人礼金和店铺多件优惠（满足门槛的情况下）按优惠金额择优生效，1个子订单仅可使用其中的1次优惠。同时可享其他类型的店铺级优惠，每个优惠类型仅可使用1次。
（2）1个子订单下单多件商品时，每件商品最多仅可使用1个店铺级优惠，整单可在“同时叠加多张店铺优惠券、1次店铺多件优惠（满N件优惠）、1次店铺新人礼金”与“1次店铺多件优惠（第N件优惠）”两种优惠组合中，择优生效。同时可享其他类型的店铺级优惠，每个优惠类型仅可使用1次。
### 3、跨店级
用户订单符合跨店级营销优惠活动的生效条件即可使用对应优惠，一个子订单最多生效1个同类型的跨店优惠（大促场景下“平台通用优惠券”类型 中“大促限时优惠券”可与“平台消费券”叠加使用），实际情况以提交订单页面为准。
### 4、其他类
用户订单符合其他类营销优惠活动的生效条件即可使用对应优惠。
