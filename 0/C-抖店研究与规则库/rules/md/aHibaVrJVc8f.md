# 第一章 概述
## 1.1 目的及依据
为营造良好的经营环境，扶持商家快速成长，现根据国家现行法律、法规、规章、平台《电子商务开放平台店铺服务协议》，制定本规则。
## 1.2 适用范围
本规则适用于平台内参与“0元入驻”的新商家，全球购、即时零售商家除外。
## 1.3 效力级别
特别规定与一般规定不一致的，适用特别规定；新的规定与旧的规定不一致的，适用新的规定。平台规则尚无规定的，根据法律规定或相关协议处理。
# 第二章 试运营规则
## 2.1 概念解析
“0元入驻”：是指允许部分新商家在无需缴纳保证金的情况下，先入驻平台进行有限制的试运营，后续通过货款逐步充值保证金至平台标准（即“保证金应缴额度”）。
## 2.2 试运营类目
2.2.1 针对新入驻抖音电商平台的商家，同时符合以下要求时，平台允许商家“0元入驻”：
商家成交：支付订单量≤200单，且支付订单总额≤10000元；
商家信用：商家不存在违规行为，或存在1次违规行为但不属于违规程度较严重的违规行为；
商家无需缴纳体验保证金；
2.2.2 若商家的关联主体历史存在违规行为或存在经营风险，平台有权限制其参与“0元入驻”，并有权视具体情况要求商家补缴保证金后方可开展经营活动。

## 2.3 试运营期店铺限制
为保障消费者权益，在试运营期间的商家店铺将受到下列限制：
| 类型 | 具体影响 |  |
| --- | --- | --- |
| 资金限制 | 货款提现要求：每个月只可提现一次，最后一笔订单签收满30天可全额提现，否则最多只可提现50%(提现最低100元) 结算账期：订单确认收货的21天后 |  |
| 营销限制 | 限制参加平台所有营销活动与精选联盟 无法使用平台补贴 仅能使用商家营销工具：赠品、搭配购、多件优惠等 |  |
注：若商家想解除如上试运营经营限制，可自主退出“0元入驻”进入正式运营阶段。具体保证金缴纳要求可见《保证金管理规范》。
## 2.4 试运营结束
2.4.1 试运营期间，若商家店铺出现以下任一情况，则试运营期结束：
商家自主选择“申请结束0元入驻”主动退出；
商家成交: 支付订单>200单，或支付订单总额>10000元；
商家信用：商家存在2次及以上的违规行为，或存在1次属于违规程度较严重的违规行为；
商家需缴纳体验保证金。
2.4.2 试运营期结束后，若商家未及时足额缴纳保证金，将受到如下管控：
（1）当保证金余额<应缴额：货款直充，限制店铺提现
（2）当保证金余额<应缴额 且 超7天未补缴： 叠加限制关联主体店铺提现，限制商品发布，限制成交
