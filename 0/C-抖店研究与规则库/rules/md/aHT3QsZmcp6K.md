# 第一章 商品信息质量分说明
## 1.1 适用范围
适用于平台内所有商家
## 1.2 指标定义
商品信息质量分是根据商品标题、属性、主图、详情、行业必要信息等，综合评估商品基础信息质量的指标。基础分为100时，商品信息为达标状态，其余情况均代表商品信息需优化。
## 1.3 指标构成
商品信息质量分，集合了商品标题、属性、主图、详情、行业必要信息等综合评估商品信息质量的指标。
商品信息质量分达标要求可参考以下信息，详细发布规范可见《商品信息发布规范》，具体商品提升建议以添加商品时页面展示为准。
商品质量分满分为100分，其中包含60分的基础分和40分的商详优化分。
其中基础分实行扣分制，即商品基础信息严重不达标影响消费者体验和平台规则的问题会扣分，同时当基础分不足60分时，将影响商品在平台营销活动中进行报名和用户搜索推荐中的展示结果；
商详优化分实行加分制，即商品商详信息完整性与丰富性有提升会加分。

| 路径3：进入商品优化独立页，查看商品信息质量分数 |  |
## 2.2 诊断调优
### 2.2.1 优化路径
| 路径1：点击「抖店PC端后台首页-不达标商品」访问商品优化页面，筛选质量分不达标/达标的商品 |  |
| --- | --- |
| 路径2：直接访问「商品-商品成长-商品优化」页面，对已发布的在线商品进行优化 |  |
| 路径3：访问商品管理列表页面——「商品-商品管理」，可查看商品信息质量分数，鼠标挪到到表情包位置，可点击“去优化”进行信息质量完善 |  |
| 路径4：点击「抖店PC端后台首页- 商城 -立即优化」，选择优化 商品详情 或 商品基础信息 ，点击“立即优化”按钮访问商品优化页面，筛选质量分不达标/达标/良好的商品 |  |
### 2.2.2 优化方式
商家可通过点击“立即优化”，进入商品编辑页，根据左侧质量分提升建议，逐条提升商品质量分；
商家可通过点击“优化基础信息”对商品属性/标题等进行批量优化，支持通过优化属性模块对商品预测属性值进行一键确认，帮助商家快捷高效地提升店铺当前在线商品的信息质量分。更多商品信息优化方式请查看《商品优化使用说明》。
# 第三章 应用场景
商品信息质量分应用于商品上架、商品曝光、成单转化、活动报名等场景。
商品上架：商品信息不达标时（低于60分）可能无法成功发布，已发布的商品可能被处理下架；
活动报名：商品信息不达标时（低于60分）将影响报名平台营销活动，具体以各营销活动规则为准；
商品曝光：商品信息质量分不达标的商品，可能影响商家商品的搜索展示露出，准确填写商品信息并提升商品信息的完整度及丰富度，将更有助于商品在搜索推荐中获得更多露出的机会；
成单转化：提升商品信息的完整度和丰富度有利于商品的点击转化。

一、案例背景 汉堡王自2021年5月以来在抖音平台长期稳定自播，不断优化货品，致力于将美味、高品质、价格合理的汉堡带给每一位用户。但是通过商城数据诊断发现，对比其他相似商家自身搜索曝光流量偏低、店铺页曝光和转化率较低。汉堡王期望提升在抖音商城场景的表现，通过提升曝光和点击转化，进而提升品牌的GMV数据。 二、诊断结论及策略方向 诊断结论： 搜索：短视频、商品卡整体曝光点击率低于相似商家，短视频和商品卡成交率较低。 店铺：店铺整体流量较相似商家低，商品曝光点击率较低。 商城推荐：商城曝光和曝光点击率低于相似商家。 核心策略： 前期阶段优化商城基建，8月底筹备百万宠粉日打造内容场+中心场+营销场的全域狂欢。 三、商城优化动作及效果 通过专项优化，汉堡王抖音商城GMV+6%（VS全店占比+4%） 搜索场景：搜索GMV提升+5%，商品曝光提升+45% 店铺场景：店铺GMV提升+13%，商品曝光提升+5% 商城场景：频道及活动页GMV提升+31%，商品曝光提升+361% 亮点动作1：搜索场景优化 搜索GMV提升+5%，商品曝光提升+45% 商品标题添加品牌词、行业热词及营销词，虚拟卡券标题直接分
