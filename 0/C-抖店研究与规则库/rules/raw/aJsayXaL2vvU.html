关于修订《商家【商品材质成分不符】细则》的公示通知

2026-10-26 17:29:48电商运营团队
为了保护消费者权益，规范商家经营行为，现修订《商家【商品材质成分不符】细则》。 ​
该规则已于2026年10月26日进行意见征集，现进行规则公示，公示期：2026年10月26日-2026年11月2日。 ​
规则预计于2026年11月3日生效，公示期满平台将另行发布正式生效规则。 ​
​
核心变化：​
针对商家出售材质成分不符商品，平台通过信息排查认定的，将商品与商家违规处置拆分，优化商家违规程度表述，详见规则3.1；通过抽检结果认定的，调整违约金上下限金额，详见规则3.3。​
规则正文：​
一、平台导向​
抖音电商致力于成为“用户发现丰富好物的首选平台”，践行“让用户高效发现好物，享受丰富美好生活”的使命。平台严格规范商品材质成分信息发布，禁止材质成分描述与实物不符，保障消费者知情权与购买体验，维护公平有序的经营环境，倡导商家诚信合规经营。​
二、违规定义​
“商品材质成分不符”指商家对商品材质成分信息的描述与商品真实材质成分比例部分不符，或材质假冒（即材质类型完全不符）。其中：​
  • 商品材质成分比例不符：指商家对商品材质成分信息的描述与商品真实的材质成分含量不符，或以掺杂、掺假、使用劣质材料等方式以假充真、以次充好。其中贵金属商品材质成分不符，指贵金属材质成分比例不符、掺杂掺假；珠宝玉石材质不符，指珠宝玉石商品部分或局部材质不符。​
  • 商品材质假冒：指商家对商品材质成分信息的描述与商品真实的材质类型完全不符。其中贵金属及珠宝玉石商品材质假冒，指贵金属或珠宝玉石商品假冒材质成分完全不符。​
三、违规处置及影响​
平台通过信息排查、消费者举证、平台抽检等方式，结合违规次数、商品材质等因素对商家进行不同的处置，以实现及时移除风险、保障用户售后、阻断违规行为的目的。​
3.1 平台通过信息排查认定商家出售材质成分不符商品​
信息层面排查认定：平台通过商品信息、店铺信息、交易行为（如规避质检等）、消费者反馈等方式，判断商家涉嫌出售材质假冒 / 材质成分不符商品。​

四、常见违规类型​
4.1 商品材质成分比例不符​
  • 商品宣传材质成分为【80%桑蚕丝+20%聚酯纤维】，检测结果显示商品材质成分为【60%桑蚕丝+40%聚酯纤维】；​
  • 贵金属材质，商品宣传成分为足金，检测结果显示商品金含量不足990‰；​
  • 珠宝玉石材质，商品宣传为碧玺，检测结果显示商品为碧玺（经局部充填）；​
  • 商品宣传羽绒服绒子含量90%，实际测试显示商品的绒子含量为80%。​
4.2 材质假冒​
商品实际材质与宣传材质完全不同，违规举例：​
  • 商品宣传100%羊毛，检测结果显示商品成分为100%腈纶；​
  • 商品宣传羽绒服，实际测试显示商品的绒子含量低于50%；​
  • 商品宣称填充物为鸭绒或鹅绒，实际检测显示填充物为飞丝、聚酯纤维等非羽绒材质；​
  • 贵金属材质，商品宣传成分为足金，检测结果显示商品成分为合金/银；​
  • 珠宝玉石材质，商品宣传为翡翠/翡翠（A货），检测结果显示商品为石英岩 / 翡翠（B 货）/ 翡翠（染色）；​
  • 木材质，商品宣传为沉香，检测结果为非沉香（低分泌物沉香木 / 白木）。​
五、经营建议及申诉​
5.1 经营建议​
  • 材质信息真实准确：严格按实物标注材质、材质成分，不夸大/虚假宣传；​
  • 材质属性：商品标题、属性、详情页、吊牌、包装上的材质信息必须统一，确保与消费者实际收到的实物材质、成分完全一致；​
  • 及时处理负向反馈：主动关注商品评价、售后、投诉中的材质问题，快速响应并整改，对问题批次立即抽检、下架，防止批量投诉导致处置升级。​
5.2 申诉​
  • 申诉路径​
  • 路径1：抖店后台-店铺-申诉与举报-申诉中心-违规申诉​
  • 路径2：抖店后台-违规管理-违规处置-违规详情-去申诉​
  • 申诉处理时效与处理结果​
商家需要在收到违规通知后7天内发起申诉，平台会在申诉页面显示申诉时间倒计时，超时将无法申诉。平台收到商家提起的申诉后，将在1-5个工作日内尽快审核商家提交的申诉材料并反馈相应处理结果。若申诉成功，则对应的处理不成立；若申诉不成功，则对应的处理成立。详见《商家申诉管理规则》。​​​
