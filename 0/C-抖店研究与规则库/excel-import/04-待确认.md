# 04 · 待确认清单（我没有证据，不编答案）

> 判定标准：**凡是模板样本里没有明文、也没有第二份样本可以对照的，全部进这里。**
> 每条给：问题 / 我为什么确定不了 / 猜错会怎样 / 要什么才能拍板。

---

## ①【阻断级】`规格1/规格2/规格3` 只有取值，没有「规格名」—— 平台从哪知道这是「颜色分类」和「尺寸」？

**问题**
模板 16 列里**没有任何一列装规格维度的名字**（没有「颜色分类」「尺码」「规格名称」这种列），只有 `规格1/规格2/规格3` 三个位置槽 + `SKU规格名称`（它是各槽取值拼起来的 `HP31054 M`）。
那么我们写进去的 `规格1=胡桃色`、`规格2=长40`，**导入后商品页上的规格名会显示成什么？** 是「颜色分类/尺寸」，还是「规格1/规格2」，还是按类目自动套一个？

**为什么确定不了**
- 样本 `SKU规格名称` 里只有值没有名（`HP31054 M` 里没有「颜色」「尺码」字样）。
- 全表无数据验证、无批注（`dataValidation` 空、`comments` 空），没有任何字段说明。
- 官方帮助文档没拿到（见 ③）。

**猜错会怎样**
最坏情况：导入成功但商品规格名变成「规格1/规格2」，买家看到的是「规格1：胡桃色」——能卖但很难看，且要逐条返工改。
次坏：平台按类目标准属性校验，名字对不上直接整批失败。

**怎么拍板**
用官方模板（③）看有没有隐藏的规格名列/sheet；或做一次 **1 个商品的试导入**，看后台商品详情里规格名显示成什么。
→ 这是**优先级最高的一条**，因为它决定「颜色分类」这个名字到底要不要在别处给。

## ②【阻断级】图片列要的是公网 URL：本地 `G:\...jpg` 能不能用？图床走哪条路？

**问题**
样本 `D3/E3/F3/N3/O3` 全是 `https://1832850322.v.123pan.cn/...`（123 网盘直链），**没有一个本地路径**。
我们采集下来的图全是本地文件（`G:\...\taobao-picker\data\v3\images\1436\main\image_xxx.jpg`）。
→ 这些图必须先变成「平台/公网能抓到的 URL」才能填进去。走哪条？

**为什么确定不了**
- 模板没写「仅支持 URL」，但样本里一个本地路径都没有，也没 `file://`。
- 抖店是否有「素材中心先上传、Excel 里填素材 ID」这条路径，模板里没有任何列能放素材 ID。

**猜错会怎样**
填本地路径 → 整批图片抓取失败，商品变成无图/待补图，导入白跑。
先往素材中心传 → 如果模板其实吃公网 URL，就多绕一道（但不会失败）。

**怎么拍板**（三选一，需人工定）
- **A 公网图床直链**（最省事，和样本一致）：需要一个能被抖店服务端访问的图床/OSS/网盘直链方案，且 URL 稳定不防盗链。
- **B 抖店素材中心**：先批量上传拿素材 ID/URL，再回填。要确认模板接受哪种形态。
- **C 本地路径（若平台支持本地上传后自动转存）**：需先用 1 个商品试导入验证。

脚本侧已备好三种模式（`--img-mode placeholder|empty|map`），**但没有一个能替你做这个决定**。

## ③【阻断级】手上这份不是平台官方模板，16 列够不够、哪些必填，全都没有依据

**问题**
`docProps` 实测：`Application = Microsoft Excel Compatible / Openpyxl 3.1.5`、`creator = openpyxl`、`lastModifiedBy = 代打哥`、WPS `KSOProductBuildVer`。
→ 这份 `UPLOAD_DEMO1.xlsx` 是**别人用脚本生成、再用 WPS 手改的「示例2模板」**，不是抖店后台导出的官方模板。`A1` 自己也写「当前模板为示例参考」。

**由此产生的连带疑问（全部无解）**：
1. 官方模板是不是有多个 sheet（`示例2` 这个命名暗示还有 `示例1`/`示例3`），每个 sheet 列集不同？
2. 这 16 列里哪些是**平台强校验必填**？样本只证明了「填了能过」，没证明「哪些不填会失败」。唯一有明文的是 `商品属性`（`A1`：「非强校验，若无也可导入」）。
3. 有没有样本里缺失但官方存在的列 —— 至少这几项在 16 列里**完全无处安放**：
   - 商品**重量/体积**（运费模板要用）
   - **运费模板** / 发货模式（现货/预售）
   - **上下架状态** / 审核备注
   - **主图视频**（我们 `plan-1436.json` 里有 2 个 mp4，现在只能丢）
   - 类目**必填属性**（如家具的「适用场景」「风格」）
4. 价格是「拼单价」，那**单买价/市场价**在哪？

**怎么拍板**
登录抖店商家后台 → 商品管理 → 批量工具 → **Excel 导入商品 → 下载官方模板**，把文件交回来。我用同一套脚本（`01`/`03` 的对照方法）再跑一遍，把差异补进 `01`。

## ④【高】`商品ID` 语义：新建商品该填什么？

**问题**
样本 `A3=31054`、`A7=31055`，4 行 SKU 重复同一值 —— 它看起来是**把多行粘成同一个商品的分组键**。
但我们是用 Excel **新建**商品，没有平台分配的商品 ID。那这列该填什么？

**三种可能，无法区分**
- 填源商品 ID（如 `1436`）当分组键，平台不理它；
- 必须留空（平台按连续行自动分组）；
- 填了不存在的 ID 会被当成「更新已有商品」而报错。

**猜错会怎样**：若平台按这列做 upsert，填 `1436` 可能报「商品不存在」整批失败；若必须填而留空，可能被合并成一个商品。

**另一个坑（样本自带）**：`A3` 是 int、`A4..A6` 是 str，同一商品 ID 类型都不统一 —— 说明平台可能按**文本**比对。我们脚本已统一成字符串。

**怎么拍板**：用官方模板看该列有无说明；或试导入 1 个商品，先填 `1436` 这种自拟值看是否报错。

## ⑤【高】规格维度的**个数**上限与**顺序**规则

**问题**
模板只有 `规格1/规格2/规格3` 三槽 → 最多 3 维？还是有第 4 维的列在官方模板里？
**顺序**：我们把「颜色分类」放 `规格1`、「尺寸」放 `规格2`。平台是否强制某一维必须在第一位（例如要求「主规格」在前）？

**样本能给的最多信息**：2 维、且 `规格1` 恒定（`HP31054` 4 行全同）也合法 —— 所以「第一维只有 1 个取值」不违法。
**没有任何** 1 维 / 4 维 / 顺序反过来的样例。

**猜错会怎样**：顺序反了通常只是显示顺序不同（可接受）；维度超 3 个会直接没地方放。

**怎么拍板**：官方模板 + 试导入一个 2 维、一个 3 维商品对比。

## ⑥【中】`SKU拼单价` 的数值格式：文本还是数字？能不能带小数？

**样本事实**：`M3='32'` 是**字符串**（`type=str`），整数、无小数位、无货币符号。
**确定不了**：`419.5` 这种带小数的怎么写？`419.00` 还是 `419.5` 还是 `419`？写成数字类型（非文本）行不行？

脚本默认 `--price-format raw`（`419.0→'419'`，`419.5→'419.5'`），另有两档 `int` / `dec2`。
**猜错会怎样**：价格精度错 1 分（抖店有最低价校验，可能报「价格低于最低限价」）。**建议先按 `dec2` 试一批**更保守。

**怎么拍板**：官方模板或帮助文档里对价格列的小数位说明。

## ⑦【中】库存 0 的 SKU 能不能导入？

**事实**：`plan-1436.json` 有一条 SKU 库存为 **0**（`528…胡桃色（长60）`，`stock: 0`）。
**确定不了**：平台是否允许导入库存 0 的 SKU（有些平台要求 ≥1，否则整行报错）。

脚本原样写了 0（不擅自改成 1）。**猜错会怎样**：整批失败，或该 SKU 被丢弃，或变成「售罄」状态（最可能，也最合理）。
**怎么拍板**：试导入时特意保留这一条，看后台怎么显示；若要避免风险，加一条「库存 <1 时跳过该 SKU」的开关（现在没加，等你定）。

## ⑧【中】`商品分类` 的层级与名称必须用平台类目树吗？

**样本**：`服装 > 内衣裤袜 > 居家服/睡衣`（3 级，半角 `>`，两侧带空格）。
**我们的**：`家具 > 几类 > 茶几/边几`（`cat=['家具','几类','茶几/边几']`）。
**确定不了**：这三级名字是不是必须逐字命中抖店类目树（我们这份 `cat` 是采集侧推出来的，未必等于平台叫法）；级数必须 3 级还是可变；末级是类目 ID 还是名称。

**猜错会怎样**：类目对不上 → 整批失败，或落到错误类目（流量更差，且属性校验会跟着错）。
**怎么拍板**：后台类目接口/官方模板里类目的正确写法（大概率要给类目 ID 或完整路径）。

---

## ⑨【中】`SKU编码` 填什么

样本 `K3..K10` 全空（`''`）→ 可空。
我们的候选：`skus[].sku_id`（如 `3260067299`）、货号（`527/528`）、留空。
**确定不了**：平台是否要求唯一、是否允许重复、留空会不会自动生成。
脚本默认填 `sku_id`。**影响**：这列是商家自己的编码，填错一般不影响导入，但影响后续 ERP/发货对账。

## ⑩【中】主图视频、重量、运费模板 —— 16 列里没有，是不是被这份「示例2」删掉了？

`plan-1436.json` 里有 `video`（2 个 mp4）、`ship_days`（2）、`ship_reason`。视频**没有任何列能放**，`ship_days` 我只能塞进 `商品属性` 当文本（`发货时效:2天`），这几乎肯定不是平台认的字段。
→ 属于 ③ 的子问题：官方模板里应该另有专门的列。**在拿到官方模板前，视频只能丢**。

## ⑪【低】`商品属性` 的键名要不要用平台标准属性名

样本：`材质:棉；品牌:范小懒`。`材质` 像标准属性名，`范小懒` 像自拟品牌名。
**确定不了**：键必须命中类目标准属性吗？值要不要命中标准值域（下拉项）？属性超长/含分号怎么办？
**影响**：`A1` 说非强校验，所以最坏是属性被忽略，不至于整批失败。

---

## ⑫【低】一行能装多少张详情图？轮播图正好 3 张是上限吗？

- 详情图 `O3` 装了 **16** 个 URL → 上限 ≥16，具体值未知。
- 轮播图只有 3 个列 → **3 张是模板给定的上限**（多于 3 张没列可放）。我们 `main` 有 **5** 张，脚本默认取前 3 张、后 2 张丢弃。**要不要改成「把第 4/5 张挪到详情图」需要你定**（现在是丢弃 + 日志）。
- 详情图 URL 总长度是否有单元格/字段长度上限未知（16 个长 URL 拼起来 `O3` 已经 1,000+ 字符，说明平台能收长文本）。

## ⑬【低】这个模板能不能**更新**已有商品，还是只能新建？

`A1` 说「导入数据包可兼容其他软件导出字段信息」——听起来只谈新建。
若这列/这套格式同时管更新（`商品ID` 命中已存在商品 = 更新），那 `商品ID` 的语义就变成「必须填真实商品 ID」，和 ④ 直接相关。

## 汇总：最需要人拍板的三条

| 排序 | 条目 | 为什么它排第一档 |
|:--|:--|:--|
| 1 | **③ 官方模板没拿到**（连带 ① 规格名、⑤ 维度上限、⑩ 视频/重量/运费） | 这一条不解决，后面全是猜；它一次性解决 5 个疑问 |
| 2 | **② 图片必须公网 URL，走图床还是素材中心** | 这是**能不能真导入**的物理前置；脚本已经写好接口，缺的是方案决定 |
| 3 | **④ `商品ID` 填什么**（自拟分组键 / 留空 / 真实商品 ID） | 猜错会整批报错，而且它决定这套格式是「新建」还是「更新」通道（连带 ⑬） |
