## 二、这套系统是怎么工作的（按你的架构）

```
① 脚本跑         batch-v4.mjs  传图→识别→标题→裁图→类目→编辑页→
                                切tab→品牌→属性→价格库存→填写检查
② 边跑边采错      每步都扫「待完善信息」+ has-error + 红字
                                → errors-<批次>.json
③ 自动补错        检查后发现属性缺失 → 回属性页补 → 再检查（最多 3 轮）
                                → errs=0 才点发布
④ 入库           导入本轮.py  → 上货错误库.sqlite3（runs/errors/lessons）
⑤ 沉淀修法        lessons 表记「哪个字段+什么症状+怎么修+哪个函数」
```

当前库内：**17 次跑批、94 条错误、11 条修法**。

## 三、这轮最有价值的 5 条经验（已写进 lessons）

| # | 坑 | 正解 |
|:--|:--|:--|
| 1 | 编辑页停在「基础信息」，价格/品牌/属性全找不到 | **必须先切 tab**：属性信息（品牌/木种/功能）、价格库存（价格/库存） |
| 2 | 只填了第一行价格，其余 SKU 报「该项为必填」 | **按 tr 逐行填**：每行 input[0]=价格、input[1]=库存，与 skus 数组按序对应 |
| 3 | 属性页看着没缺，一点「填写检查」就冒出 2-3 个必填 | **检查→补→再检查**循环，最多 3 轮，errs=0 才算好 |
| 4 | 品牌/木种/功能下拉点不开 | **键盘法**：真实鼠标点框 → ArrowDown → Enter（DOM 事件无效） |
| 5 | 发布按钮 disabled=false 不等于能发 | **必须 errs=0**；有 1 条错误时点了会静默失败 |
