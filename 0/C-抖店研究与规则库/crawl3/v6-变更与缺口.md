# 上货引擎 v6 变更与已知缺口（2026-11-02 11:10）

## 已修复并线上验证
1. SKU 缺失（根因）
   - 现象：4 个 SKU 上架后只剩 1 个，库存与 7 无关
   - 根因：脚本从不创建规格组；抖店生成后 AI 自造一个规格（材质/款式）+ 单个值，
     脚本只把 skus[0] 的价/库存填进那唯一一行 → 4 压成 1
   - 修法：normalizeSpec() —— 把 AI 造的第 1 个值改成真实规格值，再逐个补空框 + Tab
   - 验证：1391 上架后 4 行 = 1.6米/1.8米/2米/2.2米，价 3599/3999/4599/4999

2. 类目选错导致品牌被拒
   - 根因：脚本点「手动选择类目」，实测该入口不适用；类目停在 AI 默认的「桌类」，
     LZL 在该类目未授权 → 发布被拦
   - 修法：pickCategory() —— 点 class*=modifyButton 的「修改」→ 确认弹窗点「修改类目」
     → 推荐列表点「家具 > 几类 > 茶几/边几」→ 下一步
   - 验证：类目后 = 家具 > 几类 > 茶几/边几 ✓，errs=0，发布成功

3. 发布假成功
   - 修法：发布前先点「保存草稿」并校验「保存成功」；发布未确认则留在当前页不跳列表
   - 验证：B9 保存草稿 成功 / 发布 成功

4. 价格行错位（2米 抢了 2.2米）
   - 修法：规格值按长度倒序匹配 + 先比第一列文本
   - 验证：2.2米 = 4999（修复前是 4599）
